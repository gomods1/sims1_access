더 심즈 접근성 모드는 화면 낭독기와 키보드만으로 The Sims Legacy Collection을 플레이할 수 있게 해 줍니다. 모든 화면, 대화 상자, 패널을 화면 낭독기(NVDA, JAWS, 내레이터 등)로 읽어 주고, 어디서나 같은 키로 이동할 수 있게 하며, 시각 장애인 플레이어에게 필요한 도구를 더합니다. 부지의 물건 목록, 집 지도, 게임이 그림으로만 보여 주는 것을 알려 주는 내레이터, 가구를 놓을 수 있는 자리, 벽과 방을 짓는 커서가 있습니다.

게임에서 **컨트롤+시프트+F1**을 누르면 이 설명서가 게임의 언어로 열립니다. **컨트롤+F1**은 지금 있는 화면의 키를 알려 줍니다.

## 시작하기

1. 설치 프로그램을 실행하거나, `version.dll`과 `SimsAccess` 폴더를 게임 폴더(`Sims.exe`가 있는 폴더)에 복사합니다.
2. 화면 낭독기를 먼저 켠 다음 Steam에서 The Sims Legacy Collection을 실행합니다.
3. 게임 창이 열리면 "더 심즈 접근성 기능을 불러왔습니다"가 들립니다. 게임은 이웃 화면에서 시작합니다.

모드는 게임의 언어로 말합니다. 언어를 바꾸려면 Steam에서 게임의 속성, 일반, 언어로 갑니다. 모드는 영어, 프랑스어, 독일어, 이탈리아어, 스페인어, 네덜란드어, 덴마크어, 스웨덴어, 노르웨이어, 핀란드어, 브라질 포르투갈어, 일본어, 폴란드어, 중국어 간체와 번체, 태국어, 한국어로 말합니다.

모드는 현재 Steam 버전의 게임에서 작동합니다. 게임이 업데이트된 뒤 모드가 "지원하지 않는 게임 버전"이라고 말하면 모드의 다음 버전을 설치하세요.

## 이동하기: 어디서나 같은 키

모든 화면, 대화 상자, 패널, 모드는 같은 방식으로 작동합니다. 이동하는 대상은 **그룹**(대화 상자의 버튼, 욕구, 가족, 카탈로그...)이 고리처럼 이어진 것입니다. 그룹에는 **항목**이 있고, 어떤 항목은 더 깊은 **단계**를 엽니다.

| 키 | 기능 |
|---|---|
| 탭, 시프트+탭 | 다음 또는 이전 그룹. 그룹의 이름과 항목 수를 먼저 말합니다. |
| 위쪽 화살표, 아래쪽 화살표(또는 왼쪽 화살표, 오른쪽 화살표) | 그룹 안의 이전 또는 다음 항목. |
| 홈, 엔드 | 그룹의 첫 항목 또는 마지막 항목. |
| 엔터 | 항목을 누릅니다. 단계(부지 물건의 종류나 방)에서는 그것을 엽니다. |
| 스페이스 | 누릅니다. 단, 부지 화면에서는 스페이스가 게임의 "다음 심" 키입니다. |
| 백스페이스 | 한 단계 뒤로 갑니다. |
| R | 항목을 그룹과 함께 다시 말합니다. |
| 이스케이프 | 상호작용 메뉴를 닫습니다. 그 밖에는 게임 자체의 이스케이프입니다. |
| Alt+글자 | 이름이 그 글자로 시작하는 다음 그룹. |
| 컨트롤+F1 | 지금 있는 화면의 키. |
| 컨트롤+시프트+F1 | 이 설명서. |

컨트롤은 화면 낭독기처럼 이름 뒤에 종류를 말합니다: "저장, 버튼", "음향 옵션, 탭, 선택됨", "자동 중심 이동, 체크 박스, 체크됨", "특수 효과, 슬라이더, 10 중 8", "지면 디테일, 선택기, 고".

- **슬라이더, 선택기, 성격 막대**: 왼쪽과 오른쪽 화살표(또는 페이지 업과 페이지 다운)로 값을 바꿉니다. 엔터는 값을 다시 말하기만 합니다.
- **체크 박스**: 엔터로 체크하거나 해제합니다.
- **텍스트 필드**(가족과 심의 이름, 자기소개): 화살표로 필드에 가서 입력합니다. 글자마다 읽어 주고, 백스페이스는 지운 것을 말합니다. 왼쪽과 오른쪽 화살표, 홈, 엔드, 딜리트로 필드 안을 이동합니다. 화면에 텍스트 필드가 있는 동안 글자, 스페이스, R은 입력에 쓰입니다.
- **사용할 수 없는 컨트롤**은 "사용 불가"라고 말하고 눌리지 않습니다.

모든 화면의 마지막 그룹은 **모드 도움말**입니다. 그 버튼들은 그 화면의 키를 알려 주고(컨트롤+F1처럼) 이 설명서를 엽니다(컨트롤+시프트+F1처럼). 게임이 시작되면 모드는 "더 심즈 접근성 기능을 불러왔습니다" 다음에 이 두 키를 알려 줍니다.

## 더 읽기: 검토 버퍼

모든 것이 한 줄에 다 들어가지는 않습니다. 모드는 한 줄씩 읽을 수 있는 버퍼 두 개를 유지합니다:

- **세부 정보**: 방금 말한 것에 관한 모든 것. 상품의 평가, 어울리는 방, 설명. 부지 물건의 행동, 방, 거리, 판매 가격. 욕구나 기술의 설명. 컨트롤의 도움말과 그룹 안에서의 위치("12개 중 3번째, 제어판").
- **이벤트**: 일어난 일, 최신 순: 구입, 판매, 속도 변경, 대화 상자의 텍스트, 대기열에 넣은 행동, 내레이터가 말한 모든 것(최근 200개).

| 키 | 기능 |
|---|---|
| 컨트롤+위쪽 화살표 | 다음 줄, 버퍼의 더 깊은 곳으로. |
| 컨트롤+아래쪽 화살표 | 맨 위쪽으로 돌아갑니다. |
| 컨트롤+왼쪽 화살표, 컨트롤+오른쪽 화살표 | 버퍼를 전환합니다. |

## 이웃

이웃 화면의 주 그룹은 **집 목록**입니다. 각 집은 주소와 사는 사람을 말합니다. 집에서 엔터를 누르면 클릭한 것처럼 집이 눌리고, 게임 자체의 카드나 질문이 이어집니다. 집에서 컨트롤+위쪽 화살표를 누르면 세부 정보를 읽습니다. 건축 모드의 집 개요가 말할 내용을 집의 마지막 저장에서 가져온 것입니다(방, 없는 것, 들어갈 길이 없는 방). 컨트롤+시프트+L은 한 번에 모두 말합니다.

다른 그룹에는 게임의 버튼이 있습니다: 가족 만들기, 가족 보관함, 이웃 번호, 옵션, 종료.

가족이 없는 집은 무제한 자금으로 건축 모드에서만 열립니다. 모드는 금액 대신 "가족 없음, 자금 무제한"이라고 말합니다.

## 가족과 심 만들기

이 화면의 모든 것은 그룹이나 필드입니다:

- 가족 이름과 심의 이름을 각 텍스트 필드에 입력합니다.
- **성격**: 왼쪽과 오른쪽 화살표로 각 특성에 점수를 더하거나 뺍니다("10 중 4, 6점 남음"). 별자리는 점수에 따라 정해집니다.
- **외모**: 나이, 성별, 피부, 그리고 머리와 몸의 화살표. 머리와 몸마다 설명이 있습니다("머리 137개 중 3번째: 금발, 단발").
- 자기소개도 텍스트 필드입니다.
- 나중에 부지에서 컨트롤+시프트와 숫자(1부터 9)를 누르면 심의 카드가 열리고, 거기서 자기소개를 고칠 수 있습니다.

## 부지: 생활 모드

부지에서 HUD는 다른 화면처럼 그룹의 고리입니다. 탭은 다음 순서로 그룹을 돕니다:

1. **상태**: 시간, 자금, 게임 속도, 친구.
2. 선택한 심의 **욕구**, 각각 백분율로. 엔터는 그 욕구의 의미를 말합니다.
3. **가족**: 가족의 심들. 엔터로 한 명을 선택합니다.
4. **행동 대기열**: 선택한 심이 할 일. 엔터로 행동을 취소합니다.
5. **종류별 물건**과 **방별 물건**: 부지의 물건(아래 참조).
6. **제어판**, **심 패널**(기분, 관계, 직업과 기술, 성격, 관심사, 집), 그리고 여러분이 연 패널.
7. **모드 도움말**.

생활 패널의 항목(욕구, 기술, 직업, 집 평가)에서 엔터를 누르면 게임이 그 항목에 보여 주는 팝업을 읽습니다.

직업 항목은 근무 시간과 통근 차량이 오는 시간을 알려 줍니다. 게임 메뉴에는 직장을 그만두는 항목이 없습니다. 계속 결근하는 심은 해고되며, 신문과 컴퓨터에서 다른 직업을 찾을 수 있습니다.

### 심 선택과 카메라

| 키 | 기능 |
|---|---|
| 스페이스 | 게임의 "다음 심": 가족의 다음 구성원을 선택하고 알려 줍니다("Isabel, 선택됨, 먹기"). |
| 컨트롤+1부터 컨트롤+9까지 | 가족의 첫 번째부터 아홉 번째 심을 선택합니다. |
| 컨트롤+시프트+1부터 컨트롤+시프트+9까지 | 그 심의 카드(자기소개)를 엽니다. |
| 컨트롤+시프트+F | 카메라가 선택한 심을 따라가거나 자유롭게 둡니다. |
| 컨트롤+E | 선택한 심을 한 줄로: 방, 하고 있는 일, 급한 욕구, 기분. |
| P | 일시 정지(게임의 키). 모드는 시간과 자금을 말합니다. 1, 2, 3은 속도를 정합니다. |

게임의 소리는 화면에 보이는 것에서 나오기 때문에 카메라는 선택한 심을 따라갑니다. 부지의 물건을 둘러보는 동안에는 카메라가 각 물건으로 갔다가 나중에 심에게 돌아옵니다.

확대/축소와 카메라 방향은 바뀔 때 알려 주며(플러스와 마이너스로 확대/축소, 쉼표와 마침표로 시점 회전), 상태 줄에도 있습니다: "카메라: 중간 보기, 북서쪽을 향함". 방향은 화면 위쪽이 보여 주는 쪽입니다. 모드의 북쪽은 카메라와 함께 돌지 않습니다.

### 부지의 물건

부지의 모든 것은 두 그룹에 있습니다. **종류별 물건**(먼저 심즈, 그다음 구입 모드의 분류: 의자, 가구, 생활용품... 마지막으로 다른 물건)과 **방별 물건**(먼저 선택한 심이 있는 방, 그다음 다른 방들, 각각 층과 크기와 함께)입니다. 종류나 방에서 엔터를 누르면 그 안의 물건을 가까운 것부터, 선택한 심을 기준으로 "냉장고, 부엌, 북동쪽으로 6칸"처럼 나열합니다. 백스페이스는 종류나 방으로 돌아갑니다. 방 이름은 안에 있는 것을 보고 모드가 짐작한 것입니다.

탭으로 거기까지 갈 필요는 없습니다. 페이지 키는 생활, 구입, 건축 모드에서 부지의 어디서나 물건을 둘러봅니다.

| 키 | 기능 |
|---|---|
| 페이지 다운, 페이지 업 | 마지막으로 고른 종류나 방의 다음 또는 이전 물건. |
| 시프트+페이지 다운, 시프트+페이지 업 | 다음 또는 이전 물건 종류. |
| 컨트롤+페이지 다운, 컨트롤+페이지 업 | 다음 또는 이전 방(처음 누를 때: 선택한 심이 있는 방). |
| 엔터 | 물건의 상호작용(구입 모드에서는 옮기려고 집어 듭니다). |
| 컨트롤+엔터 | 선택한 심을 그 물건까지 걸어가게 합니다. |
| 컨트롤+F | 물건 찾기: 이름의 일부를 입력합니다(악센트는 구분하지 않음). 위아래 화살표로 결과를 살펴보고, 엔터로 실행하고, 컨트롤+엔터로 심을 그곳에 보내고, Delete로 문이나 창문을 제거하고, 이스케이프로 있던 곳으로 돌아갑니다. |
| Delete | 문이나 창문에서(구입 또는 건축 모드): 제거하고 돈을 돌려받습니다. |

아직 말풍선이 떠 있는 심이나 물건은 그것도 말합니다("Bella, 먹기, 생각: 허기").

심 다음은 **문제**입니다. 고장난 물건, 청소가 필요한 물건, 물웅덩이, 쓰레기, 재, 불, 파리가 꼬인 물건 등 신경 써야 할 것들입니다. 마지막은 **문, 창문, 계단**입니다.

### 상호작용 메뉴

물건(또는 심)에서 엔터를 누르면 게임의 상호작용 메뉴가 열립니다. 위쪽과 아래쪽 화살표로 고르고, 엔터로 실행하고, 이스케이프로 한 단계 뒤로 가거나 닫습니다. "..."로 끝나는 항목은 더 많은 선택지를 엽니다. 고른 행동은 대기 중이라고 알려 줍니다("말함, 대기 중"). 메뉴가 비어 있으면 모드가 이유를 말합니다("상호작용 없음. 어린이 전용: 놀기").

### 방과 집

| 키 | 기능 |
|---|---|
| 컨트롤+L | 방의 배치: 크기, 벽마다 있는 문과 창문, 그리고 그것이 이어지는 곳. 각 벽을 따라 놓인 것은 세부 정보 버퍼에 있습니다. |
| 컨트롤+시프트+L | 집 개요: 층, 방, 평가, 없는 것(변기, 샤워기, 침대, 냉장고, 레인지, 전화, 화재 경보기), 들어갈 길이 없는 방, 아무도 닿을 수 없는 물건, 어둡거나 싫어하는 방. |

### 집 지도

**컨트롤+M**은 지도를 켭니다. 선택한 심에서 시작해 집을 한 칸씩 걷는 커서입니다. 한 걸음마다 바닥, 그리고 주변의 벽, 울타리, 문, 창문마다 소리가 납니다.

| 키 | 기능 |
|---|---|
| 화살표 | 한 칸, 시프트와 함께 다섯 칸. 그곳에 있는 것과 향하는 방향, 방과 층이 바뀌면 그것도, 방향마다 벽, 울타리, 난간, 문, 창문을 말합니다. |
| 홈 | 선택한 심에게 돌아갑니다. |
| 컨트롤+시프트+페이지 업, 페이지 다운 | 위층 또는 아래층. |
| 엔터 | 그곳에 있는 것의 상호작용 메뉴. |
| 컨트롤+엔터 | 선택한 심을 그곳으로 걸어가게 합니다. |
| 페이지 다운, 페이지 업(그리고 시프트, 컨트롤) | 평소처럼 부지의 물건. 지도가 각 물건으로 갑니다. |
| R | 그 칸에 관한 모든 것. 컨트롤+L은 방의 배치. |
| 이스케이프 또는 컨트롤+M | 지도를 닫습니다. |

### 내레이터

게임은 많은 것을 그림으로만 보여 줍니다. 모드는 그것이 일어날 때 말하고 이벤트 버퍼에 남깁니다:

- 심과 물건 위의 **말풍선**: "Bella의 생각: 허기", "Mortimer의 고함: 용변", "Bella의 말: 외계인", 상대 심이 싫어하는 화제("..., 관심 없음"), "관계가 나빠짐", 그리고 "쓰레기통: 파리".
- **막힌 길**: "Bella 지나갈 수 없음: 의자이(가) 길을 막고 있음".
- 오고 가는 **방문객**, 유령, 도둑, 저승사자, 피자 배달, 통근 차와 스쿨버스(어느 차가 경적을 울리는지).
- 압류원이나 도둑이 **가져간 물건**과 그 가격, 도착한 **청구서**.
- **가족 지켜보기**: 선택한 심이 시작하는 일, 여러분이 시킨 것인지 스스로 하는 것인지("Cris, 스스로: 앉기"), 끝났을 때, 방을 옮길 때, 욕구가 낮아질 때, 기분이 빨간색으로 바뀔 때, 그날의 관계 변화("Marisa와 Cris: +8, 현재 28"), 구입 모드 밖에서 내거나 받은 돈.
- **여행**: 도착한 곳, 그리고 "집으로 돌아왔습니다".

**컨트롤+N**은 말하는 양을 바꿉니다: 전부, 경고만, 끔. 말하지 않은 줄도 이벤트 버퍼에는 들어갑니다.

들을 수 있는 소리(전화, 초인종, 경보)는 알리지 않습니다.

다른 심과 하는 행동은 누가 시작했든 상대 이름을 알려 줍니다: "호머: 인사하기, 상대: 엘비라".

### 도움말 팁과 튜토리얼

게임의 도움말 시스템에 팁이 기다리고 있으면 모드가 "도움말 시스템 팁이 있습니다. 컨트롤+H로 읽습니다"라고 말합니다. **컨트롤+H**로 팁을 엽니다. 팁을 읽어 주거나, 게임의 빨간 화살표가 가리키는 것을 말합니다.

첫 번째 이웃의 7번 집에서 게임의 튜토리얼이 진행됩니다. 각 단계는 게임 텍스트의 키보드 버전으로 읽고("확대 버튼을 누르세요. 탭으로 제어판까지, 화살표로 확대까지 가서 엔터를 누릅니다"), 이어서 화살표가 가리키는 것을 말합니다. 모든 단계를 키보드로 마칠 수 있습니다. 튜토리얼 중에 이스케이프를 처음 누르면 경고하고, 4초 안에 다시 누르면 튜토리얼을 끝냅니다.

### 피자와 다른 서비스

전화의 상호작용으로 서비스를 부릅니다. 피자 배달원은 반드시 맞이해야 합니다. 배달원이 오면 종류별 물건, 심즈로 가서 아래쪽 화살표로 배달원까지 간 다음 엔터를 누르고 "인사함"을 고릅니다. 아무도 맞이하지 않으면 배달원은 피자를 가지고 돌아가고 돈은 돌려받습니다.

## 구입 모드

F2는 구입 모드를 엽니다. 카탈로그의 분류는 탭이고 상품은 버튼입니다. 각 상품은 이름, 가격, 주요 평가, 설명을 말하고, 세부 정보 버퍼에는 모든 평가와 어울리는 방이 있습니다. 페이지의 마지막 상품을 지나가면 페이지가 넘어갑니다.

| 키 | 기능 |
|---|---|
| 컨트롤+R | 카탈로그를 한 종류의 방(부엌, 욕실, 침실, 거실, 응접실, 서재, 실외)에 맞는 상품으로 좁히거나 모두 보이게 합니다. |
| 백스페이스 | 카탈로그의 "뒤로". |
| 상품에서 엔터 | 그 상품을 놓기 시작합니다. |

### 물건 놓기

물건을 들고 있는 동안 모드는 그 물건이 들어가고 **사용할 수 있는** 자리를 이미 찾아 두었습니다(게임의 배치 검사, 방의 벽과 문, 심이 물건을 쓰는 데 필요한 공간). 각 자리는 방, 옆에 있는 것, 향하는 방향을 말합니다.

| 키 | 기능 |
|---|---|
| 페이지 다운, 페이지 업(또는 탭) | 자리들, 좋은 것부터. |
| 컨트롤+페이지 다운, 컨트롤+페이지 업 | 자리가 있는 방들. |
| 시프트+페이지 다운, 시프트+페이지 업(또는 쉼표, 마침표) | 같은 자리의 다른 방향. |
| 컨트롤+시프트+페이지 다운, 페이지 업 | 부지의 물건 옆, 가까운 것부터. |
| 화살표 | 대신 한 칸씩 옮깁니다(시프트: 다섯 칸). 들어가는지, 무엇에 부딪히는지 말합니다. |
| 엔터 | 그 자리에 구입합니다(옮길 때는 내려놓습니다). |
| 이스케이프 | 취소합니다(옮기던 물건은 제자리로 돌아갑니다). |
| 딜리트 | 들고 있는 물건을 팝니다. 환불 금액을 말합니다. |
| R | 자리를 다시 말합니다. |

세부 정보 버퍼에는 자리의 칸과, 게임이 거부한 자리와 그 이유가 있습니다.

### 옮기기와 팔기

구입 모드에서 페이지 다운으로 부지의 물건에 가서 엔터를 누릅니다. 물건을 집어 들고 같은 자리 목록이 나옵니다. 똑같은 물건은 하나씩 나열되고, 마지막으로 산 것은 "방금 구입함"이라고 말합니다.

## 건축 모드

F3은 건축 모드를 엽니다. 도구는 탭이고 도구의 스타일은 상품입니다. 건축 모드에 들어가면 집 개요를 말합니다(컨트롤+시프트+L로 다시 들을 수 있습니다).

도구를 누르면 그 도구의 모델로 이동합니다. 모델은 도구 이름이 붙은 별도 그룹에 있고, 탭으로 도구에 돌아갑니다. 모델에서 엔터를 누르기 전에는 손에 아무것도 없습니다.

### 건축 커서

벽이나 울타리 스타일에서 엔터를 누르면 선택한 심의 위치에서 건축 커서가 시작됩니다. 커서는 칸 사이의 모서리 위를 움직입니다.

| 키 | 기능 |
|---|---|
| 화살표 | 모서리 하나, 시프트와 함께 다섯. 위치, 그곳에서 만나는 벽, 그곳에 있는 것을 말합니다. |
| 스페이스 | 시작점을 표시합니다. 그러면 커서가 시작점에서의 거리와 엔터로 지을 것과 비용을 말합니다. |
| 엔터 | 시작점부터 커서까지 벽을 짓습니다. |
| 시프트+엔터 | 시작점과 커서 사이에 방의 네 벽을 짓습니다. |
| 컨트롤+엔터 또는 딜리트 | 벽을 없앱니다. |
| 쉼표, 마침표 | 기성 방의 크기를 고릅니다. |
| Insert | 커서에 북서쪽 모서리를 두고 기성 방을 짓습니다. |
| 탭, 시프트+탭(또는 컨트롤+페이지 다운, 페이지 업) | 다음 또는 이전 방으로 건너뜁니다. |
| 페이지 업, 페이지 다운 | 위층 또는 아래층. |
| 홈 | 선택한 심에게 돌아갑니다. |
| R | 모든 것: 방향마다 빈 공간, 방. |
| 이스케이프 | 커서를 떠납니다. |

짓기 전에 모드는 새 벽을 검사합니다. 벽이 심을 가두거나, 물건을 고립시키거나, 문을 막거나, 부지의 일부를 막아 버리면 그렇게 말하고, 엔터를 한 번 더 누르면 그래도 짓습니다.

### 바닥, 벽지, 수영장, 지형

이 도구들은 모두 같은 칸 커서를 씁니다(화살표, 다섯 칸은 시프트, 홈, R, 이스케이프. 자세한 것은 컨트롤+F1):

- **바닥**: 엔터는 그 칸에, 또는 스페이스로 표시한 시작점부터 사각형으로 바닥을 깝니다. 시프트+엔터는 방 전체, 컨트롤+엔터는 걷어 냅니다.
- **벽지**: 엔터는 커서가 있는 방의 모든 벽에 벽지를 바릅니다. 컨트롤+엔터는 벗겨 냅니다.
- **수영장**: 스페이스로 모서리를 표시하고 엔터로 팝니다. 물이 무언가를 고립시키면 모드가 먼저 경고합니다. 컨트롤+엔터는 칸을 다시 메웁니다. 심에게는 수영장 사다리가 필요합니다(도구 목록에 있습니다).
- **지형**: 표시한 칸부터 커서까지 평평하게 하거나, 땅을 높이거나 낮춥니다.

**잔디**도 같은 커서를 씁니다. 엔터로 커서 아래 칸을 칠합니다.

### 문, 창문, 계단

문과 창문은 가구처럼 자리 목록에서 놓습니다: "부엌의 서쪽 벽, 실외(으)로 통함, 그 방의 첫 번째 문".

화살표로 움직이면 문이나 창문이 어느 벽에 들어갈지 알려 줍니다. 돌리면 벽이 선택됩니다. 문을 놓으면 심이 지나갈 수 있는지, 무엇이 막고 있는지 알려 줍니다. 나중에 바꾸려면 **문, 창문, 계단**이나 컨트롤+F로 찾으세요. 엔터로 들어서 옮기고, Delete로 제거합니다(게임의 컨트롤+클릭).

### 지붕

지붕은 게임이 벽 위에 자동으로 짓기 때문에 커서도 배치할 것도 없습니다. 지붕 툴은 집 전체의 경사와 모델만 고릅니다. 모델에는 게임 속 이름이 없어서 모드가 색을 알려 줍니다.

## 효과음

건축 커서, 물건 놓기, 집 지도는 한 걸음마다 짧은 소리를 냅니다: 바닥, 방향마다 벽, 울타리, 문, 창문(방향마다 소리가 다릅니다), 물건, 방이 바뀔 때, 부지의 가장자리, 경사, 물건이 들어가는지 여부. **컨트롤+시프트+S**로 끄고 켭니다.

## 그 밖의 키

| 키 | 기능 |
|---|---|
| 컨트롤+시프트+C | 게임의 치트 콘솔. 위쪽과 아래쪽 화살표로 치트를 고르고, 입력하면 덧붙고, 엔터로 실행하며(다시 누르면 반복), 이스케이프로 닫습니다. |
| 컨트롤+시프트+V | 앞이 보이는 도우미를 위해 포커스가 있는 컨트롤을 화면에 표시합니다. |

## 게임 자체의 키

다음은 게임의 키이며 그대로 작동합니다:

| 키 | 기능 |
|---|---|
| F1, F2, F3, F4, F5 | 생활, 구입, 건축, 카메라, 옵션 모드. |
| P | 일시 정지. |
| 1, 2, 3 | 보통, 빠름, 가장 빠름 속도. |
| 쉼표, 마침표 | 화면 회전. |
| 더하기, 빼기 | 확대와 축소. |
| Y, N | 대화 상자의 예와 아니요. |
| 컨트롤+S | 저장. |

## 설정

모드의 설정은 게임 폴더의 `SimsAccess\SimsAccess.ini`, `[mod]` 섹션에 있습니다. 설정을 바꾸는 키는 바로 저장합니다.

| 설정 | 값 |
|---|---|
| `narrator` | 2 전부, 1 경고만, 0 끔(컨트롤+N). |
| `cues` | 1 효과음 켬, 0 끔(컨트롤+시프트+S). |
| `cue_volume` | 효과음의 음량, 0부터 100(기본값 80). |
| `show_focus` | 1이면 포커스가 있는 컨트롤을 화면에 표시합니다(컨트롤+시프트+V). |

## 문제가 생겼을 때

- **아무 소리도 나지 않음**: 게임보다 화면 낭독기를 먼저 켜세요. 모드의 로그는 `SimsAccess\SimsAccess.log`입니다. 문제를 알릴 때 함께 보내 주세요.
- **"지원하지 않는 게임 버전"**: 게임이 업데이트되었습니다. 모드의 다음 버전을 설치하세요.
- **키가 아무 일도 하지 않음**: 컨트롤+F1이 지금 있는 곳에서 쓸 수 있는 키를 알려 줍니다.

## 아직 안 된 것

Vacation, Superstar, Makin' Magic의 고유한 여행과 화면은 아직 완전히 지원하지 않습니다. 사진 모드와 카메라 모드, 가족 앨범은 시각 전용이라 제외했습니다.
