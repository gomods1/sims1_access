ม็อดการเข้าถึงเดอะซิมส์ทำให้เล่น The Sims Legacy Collection ได้ด้วยโปรแกรมอ่านหน้าจอและคีย์บอร์ดเท่านั้น ม็อดจะอ่านทุกหน้าจอ กล่องโต้ตอบ และแผงต่างๆ ผ่านโปรแกรมอ่านหน้าจอของคุณ (NVDA, JAWS, Narrator และอื่นๆ) ให้คุณไล่ดูทุกอย่างด้วยปุ่มชุดเดียวกันทุกที่ และเพิ่มเครื่องมือที่ผู้เล่นตาบอดต้องใช้ ได้แก่ รายการวัตถุในที่ดิน แผนที่บ้าน ผู้บรรยายสิ่งที่เกมแสดงเป็นภาพเท่านั้น ตำแหน่งที่วางเฟอร์นิเจอร์ได้ และเคอร์เซอร์สำหรับสร้างผนังและห้อง

กด **Control+Shift+F1** ในเกมเพื่อเปิดคู่มือนี้ในภาษาของเกม **Control+F1** บอกปุ่มของหน้าจอที่คุณอยู่

## เริ่มต้นใช้งาน

1. เรียกใช้ตัวติดตั้ง หรือคัดลอก `version.dll` และโฟลเดอร์ `SimsAccess` ไปไว้ในโฟลเดอร์ของเกม (โฟลเดอร์ที่มี `Sims.exe`)
2. เปิดโปรแกรมอ่านหน้าจอก่อน แล้วจึงเปิด The Sims Legacy Collection จาก Steam
3. เมื่อหน้าต่างเกมเปิดขึ้น คุณจะได้ยิน "โหลดม็อดการเข้าถึงเดอะซิมส์แล้ว" เกมจะเริ่มที่หน้าจอแถบที่อยู่อาศัย

ม็อดพูดภาษาเดียวกับเกม หากต้องการเปลี่ยนภาษา ให้เปิด Steam แล้วไปที่คุณสมบัติของเกม ทั่วไป ภาษา ม็อดพูดได้ภาษาอังกฤษ ฝรั่งเศส เยอรมัน อิตาลี สเปน ดัตช์ เดนมาร์ก สวีเดน นอร์เวย์ ฟินแลนด์ โปรตุเกสแบบบราซิล ญี่ปุ่น โปแลนด์ จีนตัวย่อ จีนตัวเต็ม ไทย และเกาหลี

ม็อดใช้ได้กับเกมเวอร์ชันปัจจุบันบน Steam หากเกมอัปเดตแล้วม็อดพูดว่า "ไม่รองรับเกมเวอร์ชันนี้" ให้ติดตั้งม็อดเวอร์ชันถัดไป

## การเคลื่อนที่: ปุ่มชุดเดียวใช้ได้ทุกที่

ทุกหน้าจอ กล่องโต้ตอบ แผง และโหมด ใช้งานแบบเดียวกัน สิ่งที่คุณไล่ดูคือวงของ **กลุ่ม** (ปุ่มของกล่องโต้ตอบ ความต้องการ ครอบครัว แค็ตตาล็อก...) แต่ละกลุ่มมี **รายการ** และบางรายการเปิด **ระดับ** ที่ลึกลงไปได้

| ปุ่ม | หน้าที่ |
|---|---|
| Tab, Shift+Tab | กลุ่มถัดไปหรือก่อนหน้า ชื่อกลุ่มและจำนวนรายการจะถูกพูดก่อน |
| ลูกศรขึ้น, ลูกศรลง (หรือลูกศรซ้าย, ลูกศรขวา) | รายการก่อนหน้าหรือถัดไปในกลุ่ม |
| Home, End | รายการแรกหรือรายการสุดท้ายในกลุ่ม |
| Enter | กดรายการนั้น เมื่ออยู่บนระดับ (ประเภทหรือห้องของวัตถุในที่ดิน) จะเปิดระดับนั้น |
| Space Bar | กด ยกเว้นในหน้าจอที่ดิน ซึ่ง Space Bar เป็นปุ่ม "ซิมคนถัดไป" ของเกม |
| Backspace | ถอยกลับหนึ่งระดับ |
| R | พูดรายการนั้นอีกครั้ง พร้อมกับกลุ่มของรายการ |
| Escape | ปิดเมนูการโต้ตอบ ถ้าไม่มีเมนูเปิดอยู่จะเป็น Escape ของเกมเอง |
| Alt+ตัวอักษร | กลุ่มถัดไปที่ชื่อขึ้นต้นด้วยตัวอักษรนั้น |
| Control+F1 | ปุ่มของหน้าจอที่คุณอยู่ |
| Control+Shift+F1 | คู่มือนี้ |

ตัวควบคุมจะบอกว่าตัวเองเป็นอะไรต่อจากชื่อ เหมือนที่โปรแกรมอ่านหน้าจอทำ: "เซฟ, ปุ่ม", "ตัวเลือกเสียง, แท็บ, ถูกเลือก", "เลื่อนศูนย์กลางอัตโนมัติ, กล่องกาเครื่องหมาย, กาเครื่องหมายแล้ว", "เทคนิคพิเศษ, แถบเลื่อน, 8 จาก 10", "ภูมิประเทศ, ตัวเลือกค่า, สูง"

- **แถบเลื่อน ตัวเลือกค่า และแถบอุปนิสัย**: ลูกศรซ้ายและขวา (หรือ Page Up และ Page Down) เปลี่ยนค่า Enter แค่พูดค่าอีกครั้ง
- **กล่องกาเครื่องหมาย**: Enter กาเครื่องหมายหรือเอาเครื่องหมายออก
- **ช่องข้อความ** (ชื่อครอบครัวและชื่อซิม ประวัติ): ใช้ลูกศรไปที่ช่องแล้วพิมพ์ ทุกตัวอักษรจะถูกพูดทวน และ Backspace จะบอกสิ่งที่ลบ ลูกศรซ้าย ลูกศรขวา Home, End และ Delete ใช้เลื่อนในช่อง ขณะที่มีช่องข้อความบนหน้าจอ ตัวอักษร Space Bar และ R จะใช้พิมพ์
- **ตัวควบคุมที่ใช้ไม่ได้** จะพูดว่า "ไม่พร้อมใช้งาน" และจะไม่ถูกกด

กลุ่มสุดท้ายของทุกหน้าจอคือ **ความช่วยเหลือของม็อด**: ปุ่มในกลุ่มนี้บอกปุ่มของหน้าจอนั้น (เหมือน Control+F1) และเปิดคู่มือนี้ (เหมือน Control+Shift+F1) เมื่อเกมเริ่ม ม็อดจะบอกทั้งสองปุ่มต่อจาก "โหลดม็อดการเข้าถึงเดอะซิมส์แล้ว"

## อ่านเพิ่มเติม: บัฟเฟอร์ทบทวน

ไม่ใช่ทุกอย่างจะพูดจบได้ในบรรทัดเดียว ม็อดเก็บบัฟเฟอร์สองชุดที่คุณอ่านทีละบรรทัดได้:

- **รายละเอียด**: ทุกอย่างเกี่ยวกับสิ่งที่เพิ่งพูดไป คะแนน ห้องที่เหมาะ และคำอธิบายของสินค้า การกระทำ ห้อง ระยะทาง และราคาขายของวัตถุในที่ดิน คำอธิบายของความต้องการหรือทักษะ คำแนะนำของตัวควบคุมและตำแหน่งในกลุ่ม ("3 จาก 12, ปุ่มควบคุม")
- **เหตุการณ์**: สิ่งที่เกิดขึ้น เรียงจากล่าสุด: การซื้อ การขาย การเปลี่ยนความเร็ว ข้อความในกล่องโต้ตอบ การกระทำที่เข้าคิว และทุกอย่างที่ผู้บรรยายพูด (เก็บ 200 รายการล่าสุด)

| ปุ่ม | หน้าที่ |
|---|---|
| Control+ลูกศรขึ้น | บรรทัดถัดไป ลึกเข้าไปในบัฟเฟอร์ |
| Control+ลูกศรลง | ย้อนกลับไปทางด้านบน |
| Control+ลูกศรซ้าย, Control+ลูกศรขวา | สลับระหว่างบัฟเฟอร์ |

## แถบที่อยู่อาศัย

กลุ่มหลักของหน้าจอแถบที่อยู่อาศัยคือ **บ้าน**: แต่ละหลังบอกที่อยู่และผู้ที่อาศัยอยู่ Enter บนบ้านจะกดบ้านหลังนั้นเหมือนการคลิก แล้วตามด้วยการ์ดหรือคำถามของเกมเอง เมื่ออยู่บนบ้าน Control+ลูกศรขึ้น อ่านรายละเอียดของบ้าน คือสิ่งที่ภาพรวมบ้านในโหมดสร้างจะบอก โดยใช้ข้อมูลจากการเซฟครั้งล่าสุดของบ้าน (ห้อง สิ่งที่ยังขาด ห้องที่ไม่มีทางเข้า) Control+Shift+L พูดทั้งหมดในครั้งเดียว

กลุ่มอื่นๆ มีปุ่มของเกม: สร้างครอบครัว ถังเก็บครอบครัว หมายเลขแถบที่อยู่อาศัย ตัวเลือก ออกจากเกม

บ้านที่ไม่มีครอบครัวจะเปิดได้เฉพาะโหมดสร้าง โดยมีเงินไม่จำกัด ม็อดจะพูดว่า "ไม่มีครอบครัว เงินไม่จำกัด" แทนจำนวนเงิน

## การสร้างครอบครัวและซิม

ทุกอย่างในหน้าจอเหล่านี้เป็นกลุ่มหรือช่องข้อความ:

- พิมพ์นามสกุลของครอบครัวและชื่อของซิมในช่องข้อความของแต่ละอย่าง
- **อุปนิสัย**: ลูกศรซ้ายและขวาเพิ่มหรือลดแต้มของแต่ละลักษณะ ("4 จาก 10, เหลือ 6 แต้ม") ราศีจะเปลี่ยนไปตามแต้ม
- **รูปลักษณ์**: อายุ เพศ และสีผิว รวมถึงลูกศรเลือกศีรษะและร่างกาย ศีรษะและร่างกายแต่ละแบบจะมีคำอธิบาย ("ศีรษะ 3 จาก 137: ผมสีบลอนด์, ทรงบ็อบ")
- ประวัติก็เป็นช่องข้อความเช่นกัน
- ภายหลังในที่ดิน Control+Shift กับตัวเลข (1 ถึง 9) จะเปิดการ์ดของซิม ซึ่งแก้ไขประวัติได้

## ที่ดิน: โหมดชีวิต

ในที่ดิน HUD เป็นวงของกลุ่มเหมือนหน้าจออื่นๆ Tab จะไล่ไปตามลำดับนี้:

1. **สถานะ**: เวลา เงิน ความเร็วเกม เพื่อน
2. **ความต้องการ** ของซิมที่เลือก แต่ละอย่างเป็นเปอร์เซ็นต์ Enter บอกความหมายของความต้องการนั้น
3. **ครอบครัว**: ซิมในครอบครัว Enter เลือกซิมคนนั้น
4. **คิวคำสั่ง**: สิ่งที่ซิมที่เลือกจะทำ Enter ยกเลิกการกระทำ
5. **วัตถุตามประเภท** และ **วัตถุตามห้อง**: วัตถุในที่ดิน (ดูด้านล่าง)
6. **ปุ่มควบคุม**, **แผงข้อมูลซิม** (อารมณ์ ความสัมพันธ์ งานและทักษะ อุปนิสัย ความสนใจ บ้าน) และแผงใดๆ ที่คุณเปิด
7. **ความช่วยเหลือของม็อด**

บนรายการในแผงโหมดชีวิต (ความต้องการ ทักษะ งาน คะแนนบ้าน) Enter จะอ่านป๊อปอัปของเกมสำหรับรายการนั้น

งานจะบอกเวลาทำงานและเวลาที่รถรับส่งมา ทักษะแต่ละอย่างจะบอกระดับ และเมื่อการเลื่อนตำแหน่งต้องการมากกว่านั้น จะบอกว่าต้องการเท่าไร: "การทำอาหาร, 2 จาก 10, การเลื่อนตำแหน่งครั้งต่อไปต้องการ 4" เมนูของเกมไม่มีตัวเลือกลาออก: ซิมที่ขาดงานเรื่อยๆ จะถูกไล่ออก และหนังสือพิมพ์กับคอมพิวเตอร์มีงานอื่นให้เลือก

### การเลือกซิมและกล้อง

| ปุ่ม | หน้าที่ |
|---|---|
| Space Bar | "ซิมคนถัดไป" ของเกม: เลือกสมาชิกครอบครัวคนถัดไปและประกาศ ("Isabel, ถูกเลือก, กิน") |
| Control+1 ถึง Control+9 | เลือกซิมคนที่หนึ่งถึงคนที่เก้าของครอบครัว |
| Control+Shift+1 ถึง Control+Shift+9 | เปิดการ์ดของซิมคนนั้น (ประวัติ) |
| Control+Shift+F | กล้องติดตามซิมที่เลือก หรือเคลื่อนที่อิสระ |
| Control+E | ซิมที่เลือกในบรรทัดเดียว: ห้อง สิ่งที่กำลังทำ ความต้องการเร่งด่วน อารมณ์ |
| Control+Shift+E | รูปลักษณ์ของซิม: ศีรษะและร่างกาย ("ศีรษะ: ผมดำ, สั้น; ร่างกาย: สูท, สีดำ") ซิมที่โฟกัสอยู่ในวัตถุของที่ดิน ถ้าไม่มีก็ซิมที่เลือก รายละเอียดของซิม (Control+ลูกศรขึ้นบนซิมนั้น) ก็บอกเช่นกัน |
| Control+T | บอกทุกชั่วโมงใหม่ของนาฬิกา ("ขณะนี้เวลา 14:00") หรือหยุดบอก มีประโยชน์ที่ความเร็วสูงสุด |
| P | หยุดเกม (ปุ่มของเกม) ม็อดจะบอกเวลาและเงิน 1, 2, 3 ตั้งความเร็ว |

กล้องติดตามซิมที่เลือก เพราะเสียงของเกมมาจากสิ่งที่อยู่บนหน้าจอ ขณะที่คุณไล่ดูวัตถุในที่ดิน กล้องจะไปที่วัตถุแต่ละชิ้นแล้วกลับมาที่ซิมในภายหลัง

การซูมและทิศของกล้องจะบอกเมื่อเปลี่ยน (บวกและลบซูม, จุลภาคและจุดหมุนมุมมอง) และมีในบรรทัดสถานะด้วย: "กล้อง: มุมมองกลาง, หันไปทางทิศตะวันตกเฉียงเหนือ" ทิศคือสิ่งที่ด้านบนของหน้าจอแสดง ทิศเหนือของม็อดไม่หมุนตามกล้อง

### วัตถุในที่ดิน

ทุกอย่างในที่ดินอยู่ในสองกลุ่ม: **วัตถุตามประเภท** (ชาวซิมก่อน จากนั้นเป็นหมวดหมู่ของโหมดซื้อ: ที่นั่ง โต๊ะ เครื่องใช้ในครัวเรือน... แล้วจึงเป็นวัตถุอื่นๆ) และ **วัตถุตามห้อง** (ห้องของซิมที่เลือกก่อน แล้วจึงเป็นห้องอื่นๆ แต่ละห้องบอกชั้นและขนาด) Enter บนประเภทหรือห้องจะแสดงรายการวัตถุในนั้น เริ่มจากที่ใกล้ที่สุด เช่น "ตู้เย็น, ห้องครัว, ห่าง 6 ช่อง ทางทิศตะวันออกเฉียงเหนือ" นับจากซิมที่เลือก Backspace กลับไปที่ประเภทหรือห้อง ชื่อห้องเป็นการเดาของม็อดจากสิ่งที่อยู่ในห้อง

คุณไม่ต้องกด Tab ไปที่นั่น: ปุ่ม Page ไล่ดูวัตถุได้จากทุกที่ในที่ดิน ทั้งในโหมดชีวิต โหมดซื้อ และโหมดสร้าง

| ปุ่ม | หน้าที่ |
|---|---|
| Page Down, Page Up | วัตถุถัดไปหรือก่อนหน้าของประเภทหรือห้องที่เลือกล่าสุด |
| Shift+Page Down, Shift+Page Up | ประเภทวัตถุถัดไปหรือก่อนหน้า |
| Control+Page Down, Control+Page Up | ห้องถัดไปหรือก่อนหน้า (การกดครั้งแรก: ห้องของซิมที่เลือก) |
| Enter | การโต้ตอบของวัตถุ (ในโหมดซื้อ: ยกขึ้นเพื่อย้าย) บนรายการของสิ่งที่เหมือนกัน ("เก้าอี้พับ, เหมือนกัน 4 ตัว"): แสดงทีละชิ้น เริ่มจากที่ใกล้ที่สุด Backspace ย้อนกลับ |
| Control+Enter | ให้ซิมที่เลือกเดินไปที่วัตถุนั้น |
| Control+F | ค้นหาสิ่งของ: พิมพ์บางส่วนของชื่อ (ไม่สนใจเครื่องหมายเน้นเสียง) ลูกศรขึ้นและลงไล่ดูผลลัพธ์, Enter ทำกับสิ่งนั้น, Control+Enter ให้ซิมเดินไปที่นั่น, Delete เอาประตูหรือหน้าต่างออก, Escape กลับไปที่เดิม |
| Delete | บนประตูหรือหน้าต่าง ในโหมดซื้อหรือโหมดสร้าง: เอาออกและคืนเงิน |

ซิมหรือวัตถุที่ยังมีบอลลูนแสดงอยู่จะบอกบอลลูนนั้นด้วย ("Bella, กิน, คิด: ความหิว") สิ่งที่ไม่มีซิมคนไหนไปถึงได้จากทางเข้าที่ดินจะบอกว่า "ไม่มีซิมคนไหนไปถึงได้"

ต่อจากซิมคือ **ปัญหา**: สิ่งที่ต้องดูแล เช่น ของเสีย ของที่ต้องทำความสะอาด แอ่งน้ำ ขยะ ขี้เถ้า ไฟ และอะไรก็ตามที่มีแมลงวัน สุดท้ายคือ **ประตู หน้าต่าง และบันได**

### เมนูการโต้ตอบ

Enter บนวัตถุ (หรือบนซิม) เปิดเมนูการโต้ตอบของเกม ลูกศรขึ้นและลงเลือก Enter ทำสิ่งนั้น Escape ย้อนกลับหนึ่งระดับหรือปิดเมนู รายการที่ลงท้ายด้วย "..." จะเปิดตัวเลือกเพิ่มเติม การกระทำที่เลือกจะถูกบอกว่าอยู่ในคิว ("พูดคุย, อยู่ในคิว") เมื่อเมนูว่าง ม็อดจะบอกเหตุผล ("ไม่มีการโต้ตอบ สำหรับเด็กเท่านั้น: เล่น")

### ห้องและบ้าน

| ปุ่ม | หน้าที่ |
|---|---|
| Control+L | ผังของห้อง: ขนาด ประตูและหน้าต่างในแต่ละผนังและทางที่เปิดออกไป สิ่งที่ตั้งอยู่ตามผนังแต่ละด้านอยู่ในบัฟเฟอร์รายละเอียด |
| Control+Shift+L | ภาพรวมบ้าน: ชั้น ห้อง คะแนน สิ่งที่ยังขาด (ส้วม ฝักบัว เตียง ตู้เย็น เตา โทรศัพท์ เครื่องตรวจจับควัน) ห้องที่ไม่มีทางเข้า วัตถุที่ไม่มีใครเข้าถึงได้ ห้องที่มืดหรือห้องที่ซิมไม่ชอบ |

### แผนที่บ้าน

**Control+M** เปิดแผนที่: เคอร์เซอร์ที่เดินไปทั่วบ้านทีละช่อง โดยเริ่มจากซิมที่เลือก ทุกก้าวจะเล่นเสียงของพื้น และของผนัง รั้ว ประตู หรือหน้าต่างแต่ละอย่างรอบๆ

| ปุ่ม | หน้าที่ |
|---|---|
| ปุ่มลูกศร | หนึ่งช่อง กด Shift ร่วมด้วยห้าช่อง บอกว่ามีอะไรตั้งอยู่และหันไปทางไหน บอกห้องและชั้นเมื่อเปลี่ยน รวมทั้งผนัง รั้ว ราวกั้น ประตู และหน้าต่างในแต่ละด้าน ผนัง รั้ว และหน้าต่างจะหยุดเคอร์เซอร์ ประตูให้ผ่านไปได้ |
| Alt+ปุ่มลูกศร | เหมือนกัน แต่ทะลุผนัง |
| ลูกน้ำ, จุด | สิ่งที่แต่ละก้าวบอก: ทั้งหมด เฉพาะวัตถุ เฉพาะพื้น (ตามชื่อ "กระเบื้องหินแกรนิตสีอ่อน") เฉพาะผนัง เฉพาะห้อง |
| Home | กลับไปที่ซิมที่เลือก |
| Control+Shift+Page Up, Page Down | ชั้นบนหรือชั้นล่าง |
| Enter | เมนูการโต้ตอบของสิ่งที่ตั้งอยู่ตรงนั้น (สิ่งที่อยู่บนโต๊ะหรือโต๊ะทำงานมาก่อนโต๊ะ: คอมพิวเตอร์ ไม่ใช่โต๊ะของมัน) |
| Control+Enter | ให้ซิมที่เลือกเดินไปที่นั่น |
| Page Down, Page Up (และ Shift, Control) | วัตถุในที่ดินเหมือนเดิม แผนที่จะไปที่วัตถุแต่ละชิ้น |
| R | ทุกอย่างเกี่ยวกับช่องนั้น Control+L บอกผังของห้อง |
| Escape หรือ Control+M | ออกจากแผนที่ |

### ผู้บรรยาย

เกมแสดงหลายสิ่งเป็นภาพเท่านั้น ม็อดจะพูดสิ่งเหล่านั้นทันทีที่เกิดขึ้นและเก็บไว้ในบัฟเฟอร์เหตุการณ์:

- **บอลลูน** เหนือซิมและวัตถุ: "Bella คิด: ความหิว", "Mortimer ตะโกน: ขับถ่าย", "Bella พูด: มนุษย์ต่างดาว", หัวข้อที่ซิมอีกคนไม่ชอบ ("..., ไม่สนใจ"), "ความสัมพันธ์แย่ลง" และ "ถังขยะ: แมลงวัน"
- **เส้นทางที่ถูกขวาง**: "Bella ผ่านไปไม่ได้: เก้าอี้ ขวางทางอยู่"
- **ผู้มาเยือน** ที่มาถึงและจากไป วิญญาณ ขโมย ยมทูต คนส่งพิซซ่า รถรับส่งและรถโรงเรียน (รถคันไหนบีบแตร)
- **ของที่ถูกเอาไป** โดยพนักงานยึดทรัพย์หรือขโมย พร้อมมูลค่า และ **บิล** ที่มาถึง
- **การเฝ้าดูครอบครัว**: สิ่งที่ซิมที่เลือกเริ่มทำ ตามคำสั่งของคุณหรือทำเอง ("Cris ทำเอง: นั่ง") เมื่อทำเสร็จหรือถูกขัดจังหวะ ("Cris หยุด นั่ง เพื่อ ตื่นตระหนก และสิ่งที่ทำอยู่ยังรอในคิว") การเปลี่ยนห้อง ความต้องการที่ลดต่ำ อารมณ์ที่กลายเป็นสีแดง ความสัมพันธ์ที่เปลี่ยนในวันนั้น ("Marisa กับ Cris: +8 ตอนนี้ 28" แผงความสัมพันธ์ของเกมก็แสดงตัวเลขเหล่านี้เช่นกัน) และเงินที่จ่ายหรือได้รับนอกโหมดซื้อ
- **การเดินทาง**: ที่ที่คุณไปถึง และ "กลับถึงบ้านแล้ว"

**Control+N** เปลี่ยนปริมาณที่พูด: ทั้งหมด เฉพาะคำเตือน หรือปิด บรรทัดที่ไม่ได้พูดยังคงเข้าไปในบัฟเฟอร์เหตุการณ์

**Control+Shift+N** เลือกว่าจะพูดบทสนทนาของใคร (สิ่งที่ซิมพูด การเข้าสังคม และความสัมพันธ์ที่เปลี่ยนจากสิ่งเหล่านั้น): ทุกคนที่คุยกับครอบครัวของคุณ (ค่าเริ่มต้น) ทุกคนในที่ดิน เฉพาะครอบครัวของคุณ หรือไม่มีใคร

เสียงที่คุณได้ยินเอง (โทรศัพท์ กริ่งประตู สัญญาณเตือน) จะไม่ถูกประกาศ

การกระทำกับซิมอื่นจะบอกชื่อซิมนั้น ไม่ว่าใครเป็นคนเริ่ม: "โฮเมอร์: ทักทาย, กับ เอลวิรา"

### เคล็ดลับและแบบฝึก

เมื่อระบบช่วยเหลือของเกมมีเคล็ดลับรออยู่ ม็อดจะพูดว่า "มีเคล็ดลับจากระบบช่วยเหลือ: Control+H อ่านเคล็ดลับ" **Control+H** เปิดเคล็ดลับนั้น: เคล็ดลับจะถูกอ่าน หรือม็อดจะบอกว่าลูกศรสีแดงของเกมชี้ไปที่อะไร

บ้านหลังที่ 7 ของแถบที่อยู่อาศัยแรกจะเริ่มแบบฝึกของเกม แต่ละขั้นจะอ่านเป็นข้อความของเกมฉบับสำหรับคีย์บอร์ด ("ให้กดปุ่มซูมเข้า: Tab ไปที่กลุ่มปุ่มควบคุม, ปุ่มลูกศรไปที่ซูมเข้า, Enter") ตามด้วยสิ่งที่ลูกศรชี้ ทุกขั้นทำได้ด้วยคีย์บอร์ด การกด Escape ครั้งแรกระหว่างแบบฝึกจะเตือนคุณ การกด Escape ครั้งที่สองภายในสี่วินาทีจะออกจากแบบฝึก

### พิซซ่าและบริการอื่นๆ

ใช้การโต้ตอบของโทรศัพท์เพื่อเรียกบริการ ต้องมีคนต้อนรับคนส่งพิซซ่า: เมื่อเขามาถึง ให้ไปที่วัตถุตามประเภท เลือกชาวซิม ลูกศรลงไปที่เขา กด Enter แล้วเลือกต้อนรับ ถ้าไม่มีใครต้อนรับ เขาจะกลับไปพร้อมพิซซ่าและเงินจะคืนมา

## โหมดซื้อ

F2 เปิดโหมดซื้อ หมวดหมู่ของแค็ตตาล็อกเป็นแท็บ และสินค้าเป็นปุ่ม: สินค้าแต่ละชิ้นบอกชื่อ ราคา คะแนนหลัก และคำอธิบาย บัฟเฟอร์รายละเอียดมีคะแนนทั้งหมดและห้องที่สินค้านั้นเหมาะ การเลื่อนเลยสินค้าชิ้นสุดท้ายของหน้าจะพลิกหน้าให้

| ปุ่ม | หน้าที่ |
|---|---|
| Control+R | ให้แค็ตตาล็อกแสดงเฉพาะสินค้าสำหรับห้องประเภทเดียว (ห้องครัว ห้องน้ำ ห้องนอน ห้องนั่งเล่น ห้องทานอาหาร ห้องทำงาน นอกบ้าน) หรือทั้งหมด |
| Backspace | "กลับ" ของแค็ตตาล็อก |
| Enter บนสินค้า | เริ่มวางสินค้านั้น |

### การวางวัตถุ

ขณะที่คุณถือวัตถุอยู่ ม็อดได้หาตำแหน่งที่วางได้ **และใช้งานได้** ไว้แล้ว (การตรวจการวางของเกม ผนังและประตูของห้อง พื้นที่ที่ซิมต้องใช้เพื่อใช้งานวัตถุ) แต่ละตำแหน่งบอกห้อง สิ่งที่อยู่ข้างๆ และทิศที่หันไป

| ปุ่ม | หน้าที่ |
|---|---|
| Page Down, Page Up (หรือ Tab) | ตำแหน่งต่างๆ เริ่มจากที่ดีที่สุด |
| Control+Page Down, Control+Page Up | ห้องที่มีตำแหน่งวาง |
| Shift+Page Down, Shift+Page Up (หรือลูกน้ำ, จุด) | ทิศทางอื่นในตำแหน่งเดิม |
| Control+Shift+Page Down, Page Up | ข้างวัตถุในที่ดิน เริ่มจากที่ใกล้ที่สุด |
| ปุ่มลูกศร | เลื่อนทีละช่องแทน (Shift: ห้าช่อง) และบอกว่าวางได้ไหมและชนกับอะไร ผนัง รั้ว และหน้าต่างจะหยุดวัตถุ ประตูให้ผ่านไปได้ |
| Alt+ปุ่มลูกศร | เหมือนกัน แต่ทะลุผนัง |
| Enter | ซื้อและวางที่นั่น (หรือวางลง เมื่อกำลังย้าย) |
| Escape | ยกเลิก (วัตถุที่ย้ายจะกลับที่เดิม) |
| Delete | ขายวัตถุที่ถืออยู่ และบอกเงินที่ได้คืน |
| R | พูดตำแหน่งอีกครั้ง |

บัฟเฟอร์รายละเอียดมีช่องของตำแหน่งนั้น และตำแหน่งที่เกมปฏิเสธพร้อมเหตุผล

ตำแหน่งของที่นั่งจะเริ่มจากที่ที่มีของซึ่งใช้แบบนั่งและยังไม่มีที่นั่ง: "หันไปทางทิศใต้, เพื่อใช้ คอมพิวเตอร์ แบบนั่ง" หลังจากวางวัตถุแล้ว ม็อดจะบอกว่าจะใช้งานอย่างไร: "เพื่อใช้ คอมพิวเตอร์ แบบนั่ง", "ใช้จาก เก้าอี้สำนักงาน", "ซิมไปถึงได้" หรือ "ไม่มีซิมคนไหนไปถึงได้"

### การย้ายและการขาย

ในโหมดซื้อ ให้กด Page Down ไปที่วัตถุในที่ดินแล้วกด Enter: วัตถุจะถูกยกขึ้นและรายการตำแหน่งชุดเดียวกันจะปรากฏ เริ่มจากห้องที่วัตถุนั้นอยู่ ลูกศรครั้งแรกจะวางเคอร์เซอร์ที่ตำแหน่งเดิมของมัน วัตถุที่เหมือนกันจะแสดงทีละชิ้น และสิ่งที่ซื้อล่าสุดจะบอกว่า "เพิ่งซื้อ"

## โหมดสร้าง

F3 เปิดโหมดสร้าง เครื่องมือของโหมดนี้เป็นแท็บ และแบบของเครื่องมือเป็นสินค้า ภาพรวมบ้านจะถูกพูดเมื่อคุณเข้าโหมดสร้าง (Control+Shift+L พูดซ้ำ)

การกดเครื่องมือจะพาไปยังแบบของเครื่องมือนั้น ในกลุ่มแยกต่างหากที่ใช้ชื่อเครื่องมือ; Tab กลับไปที่เครื่องมือ คุณจะยังไม่ถืออะไรจนกว่าจะกด Enter บนแบบ

### เคอร์เซอร์ก่อสร้าง

Enter บนแบบผนังหรือรั้วจะเริ่มเคอร์เซอร์ก่อสร้างที่ซิมที่เลือก เคอร์เซอร์เลื่อนไปบนมุมระหว่างช่อง

| ปุ่ม | หน้าที่ |
|---|---|
| ปุ่มลูกศร | หนึ่งมุม กด Shift ร่วมด้วยห้ามุม บอกตำแหน่ง ผนังที่มาบรรจบกันตรงนั้น และสิ่งที่ตั้งอยู่ตรงนั้น |
| Space Bar | ตั้งจุดเริ่ม จากนั้นเคอร์เซอร์จะบอกระยะจากจุดเริ่ม และสิ่งที่ Enter จะสร้างพร้อมราคา |
| Enter | สร้างผนังจากจุดเริ่มถึงเคอร์เซอร์ |
| Shift+Enter | สร้างผนังสี่ด้านของห้องระหว่างจุดเริ่มกับเคอร์เซอร์ |
| Control+Enter หรือ Delete | รื้อผนัง |
| ลูกน้ำ, จุด | เลือกขนาดห้องสำเร็จรูป |
| Insert | สร้างห้องสำเร็จรูปโดยมีมุมตะวันตกเฉียงเหนืออยู่ที่เคอร์เซอร์ |
| Tab, Shift+Tab (หรือ Control+Page Down, Page Up) | ข้ามไปห้องถัดไปหรือก่อนหน้า |
| Page Up, Page Down | ชั้นบนหรือชั้นล่าง |
| Home | กลับไปที่ซิมที่เลือก |
| R | ทุกอย่าง: พื้นที่ว่างในแต่ละทิศ ห้อง |
| Escape | ออกจากเคอร์เซอร์ |

ก่อนสร้าง ม็อดจะตรวจผนังใหม่ ถ้าผนังจะขังซิมไว้ ทำให้วัตถุเข้าถึงไม่ได้ ปิดประตู หรือตัดบางส่วนของที่ดินออกไป ม็อดจะบอก และกด Enter ครั้งที่สองเพื่อสร้างต่อ

### พื้น วอลเปเปอร์ สระ และภูมิประเทศ

เครื่องมือเหล่านี้มีเคอร์เซอร์บนช่องแบบเดียวกัน (ปุ่มลูกศร Shift ห้าช่อง Home, R, Escape และดูรายละเอียดด้วย Control+F1):

- **พื้น**: Enter ปูพื้นช่องนั้น หรือปูเป็นรูปสี่เหลี่ยมจากจุดเริ่มที่ตั้งด้วย Space Bar, Shift+Enter ปูทั้งห้อง, Control+Enter รื้อพื้น
- **วอลเปเปอร์**: Enter ติดวอลเปเปอร์ทุกผนังของห้องที่เคอร์เซอร์อยู่, Control+Enter ลอกออก
- **สระ**: Space Bar ตั้งมุม Enter ขุด ม็อดจะเตือนก่อนถ้าน้ำจะตัดขาดสิ่งใด Control+Enter ถมช่องกลับ ซิมต้องมีบันไดสระ (อยู่ในรายการของเครื่องมือ)
- **ภูมิประเทศ**: ปรับระดับจากช่องที่ตั้งไว้ถึงเคอร์เซอร์ หรือยกและลดระดับพื้นดิน

**หญ้า** ใช้เคอร์เซอร์เดียวกัน: Enter ระบายช่องที่อยู่ใต้เคอร์เซอร์

### ประตู หน้าต่าง และบันได

ประตูและหน้าต่างวางเหมือนเฟอร์นิเจอร์ จากรายการตำแหน่ง: "ในผนังด้านทิศตะวันตกของห้องครัว เปิดสู่นอกบ้าน, ประตูแรกของห้องนั้น"

เมื่อใช้ลูกศร ประตูหรือหน้าต่างจะบอกว่าจะอยู่ในกำแพงใด การหมุนคือการเลือกกำแพง หลังวางประตู ม็อดจะบอกว่าซิมเดินผ่านได้หรือไม่ หรืออะไรขวางอยู่ หากจะเปลี่ยนภายหลัง ให้หาใน **ประตู หน้าต่าง และบันได** หรือด้วย Control+F: Enter หยิบขึ้นเพื่อย้าย, Delete เอาออก (Control+คลิกของเกม)

### หลังคา

เกมสร้างหลังคาให้เองเหนือกำแพง จึงไม่มีเคอร์เซอร์และไม่มีอะไรต้องวาง เครื่องมือสร้างหลังคาเลือกแค่ความลาดเอียงและแบบสำหรับทั้งบ้าน แบบต่างๆ ไม่มีชื่อในเกม: ม็อดจะบอกสีของมัน

## เสียงบอกตำแหน่ง

เคอร์เซอร์ก่อสร้าง การวางวัตถุ และแผนที่บ้าน จะเล่นเสียงสั้นๆ ในทุกก้าว: พื้น ผนัง รั้ว ประตู หรือหน้าต่างของแต่ละด้าน (แต่ละด้านมีเสียงต่างกัน) วัตถุ การเปลี่ยนห้อง ขอบที่ดิน ทางลาด และวัตถุวางได้หรือไม่ **Control+Shift+S** ปิดและเปิดเสียงเหล่านี้

## ปุ่มอื่นๆ

| ปุ่ม | หน้าที่ |
|---|---|
| Control+Shift+C | คอนโซลสูตรโกงของเกม ลูกศรขึ้นและลงเลือกสูตร การพิมพ์จะต่อท้าย Enter ใช้สูตร (กดอีกครั้ง: ใช้ซ้ำ) Escape ปิด |
| Control+Shift+V | ไฮไลต์ตัวควบคุมที่โฟกัสอยู่บนหน้าจอ สำหรับผู้ช่วยที่มองเห็น ในที่ดิน ตัวชี้เมาส์จะไปที่สิ่งที่โฟกัสอยู่ด้วย |

## ปุ่มของเกมเอง

ปุ่มเหล่านี้เป็นของเกม และยังใช้ได้:

| ปุ่ม | หน้าที่ |
|---|---|
| F1, F2, F3, F4, F5 | โหมดชีวิต โหมดซื้อ โหมดสร้าง โหมดกล้องถ่ายภาพ และโหมดตัวเลือก |
| P | หยุดเกม |
| 1, 2, 3 | ความเร็วปกติ เร็ว และเร็วที่สุด |
| ลูกน้ำ, จุด | หมุนมุมมอง |
| เครื่องหมายบวก, เครื่องหมายลบ | ซูมเข้าและซูมออก |
| Y, N | ใช่และไม่ในกล่องโต้ตอบ |
| Control+S | เซฟ |

## การตั้งค่า

การตั้งค่าของม็อดอยู่ใน `SimsAccess\SimsAccess.ini` ในโฟลเดอร์ของเกม ส่วน `[mod]` ปุ่มที่เปลี่ยนการตั้งค่าจะบันทึกทันที

| การตั้งค่า | ค่า |
|---|---|
| `narrator` | 2 ทั้งหมด, 1 เฉพาะคำเตือน, 0 ปิด (Control+N) |
| `cues` | 1 เปิดเสียงบอกตำแหน่ง, 0 ปิด (Control+Shift+S) |
| `cue_volume` | ระดับเสียงของเสียงบอกตำแหน่ง 0 ถึง 100 (ค่าเริ่มต้น 80) |
| `show_focus` | 1 ไฮไลต์ตัวควบคุมที่โฟกัสอยู่บนหน้าจอ (Control+Shift+V) |
| `social` | บทสนทนาของใครที่จะพูด: 3 ทุกคน, 2 ทุกคนที่คุยกับครอบครัวของคุณ, 1 ครอบครัวของคุณ, 0 ไม่มีใคร (Control+Shift+N) |
| `hours` | 1 บอกทุกชั่วโมงใหม่ (Control+T) |

## เมื่อมีปัญหา

- **ไม่มีเสียงพูดเลย**: เปิดโปรแกรมอ่านหน้าจอก่อนเปิดเกม บันทึกของม็อดคือ `SimsAccess\SimsAccess.log` ให้ส่งไฟล์นี้มาพร้อมรายงานปัญหา
- **"ไม่รองรับเกมเวอร์ชันนี้"**: เกมอัปเดตแล้ว ให้ติดตั้งม็อดเวอร์ชันถัดไป
- **กดปุ่มแล้วไม่มีอะไรเกิดขึ้น**: Control+F1 บอกว่าปุ่มไหนใช้ได้ในที่ที่คุณอยู่

## สิ่งที่ยังไม่เสร็จ

การเดินทางและหน้าจอเฉพาะของ Vacation, Superstar และ Makin' Magic ยังรองรับไม่ครบ โหมดกล้องถ่ายภาพและอัลบั้มครอบครัวเป็นสิ่งที่มองเห็นได้อย่างเดียว จึงไม่ได้รวมไว้
