模拟人生无障碍模组让你只用屏幕阅读器和键盘就能玩 The Sims Legacy Collection。它通过你的屏幕阅读器（NVDA、JAWS、讲述人等）朗读每个画面、对话框和面板，让你在任何地方都用同样的按键浏览，并加入盲人玩家需要的工具：地块物品列表、房屋地图、为游戏只用画面表现的内容配上的旁白、能放下家具的位置，以及建造墙壁和房间用的光标。

在游戏中按 **Ctrl+Shift+F1** 打开本手册，语言与游戏相同。**Ctrl+F1** 说出当前画面的按键。

## 开始使用

1. 运行安装程序，或者把 `version.dll` 和 `SimsAccess` 文件夹复制到游戏文件夹（有 `Sims.exe` 的那个）。
2. 先启动屏幕阅读器，再从 Steam 启动 The Sims Legacy Collection。
3. 游戏窗口打开时，你会听到“模拟人生无障碍模组已加载”。游戏从街区画面开始。

模组使用游戏的语言。要更改语言，打开 Steam，进入游戏的“属性”，然后是“通用”、“语言”。模组支持英语、法语、德语、意大利语、西班牙语、荷兰语、丹麦语、瑞典语、挪威语、芬兰语、巴西葡萄牙语、日语、波兰语、简体中文、繁体中文、泰语和韩语。

模组适用于游戏当前的 Steam 版本。如果游戏更新后模组说“不支持的游戏版本”，请安装模组的下一个版本。

## 四处移动：一套按键通用

每个画面、对话框、面板和模式的用法都一样。你浏览的是一圈**组**（对话框的按钮、需求、家庭、目录……）。每个组包含若干**项**，有些项还能打开更深一层的**层级**。

| 按键 | 作用 |
|---|---|
| Tab, Shift+Tab | 下一个或上一个组。先说出组的名称和项数。 |
| 上方向键、下方向键（或左方向键、右方向键） | 组内的上一项或下一项。 在购买模式和建筑模式的目录中，左方向键和右方向键改为翻页。 |
| Home, End | 组内的第一项或最后一项。 |
| 回车 | 激活该项。在层级上（地块物品的某个类型或房间）则打开它。 |
| 空格键 | 激活，但在地块画面中除外：那里的空格键是游戏的“下一个模拟市民”键。 |
| 退格键 | 返回上一层级。 |
| R | 再说一遍当前项，连同它所在的组。 |
| Esc | 关闭互动菜单；否则是游戏自己的 Esc。 |
| Alt+字母 | 名称以该字母开头的下一个组。 |
| Ctrl+F1 | 当前画面的按键。 |
| Ctrl+Shift+F1 | 本手册。 |

控件会在名称后说出自己的类型，就像屏幕阅读器那样：“存储进度，按钮”、“声音选项，选项卡，已选中”、“事件自动中心化，复选框，已勾选”、“F/X，滑块，8，最大10”、“地形细节，选择器，高”。

- **滑块、选择器和性格条**：左右方向键（或 Page Up 和 Page Down）调整数值。回车只会再说一遍数值。
- **复选框**：回车勾选或取消勾选。
- **文本框**（家庭和模拟市民的名字、个人简介）：用方向键移到文本框上，然后输入。每个字都会被读出，退格键会说出删掉的内容。左右方向键、Home、End 和 Delete 在文本框内移动。只要画面上有文本框，字母、空格键和 R 都用来输入。
- **不可用的控件**会说“不可用”，不会被激活。

每个画面的最后一组是**模组帮助**：其中的按钮会说出该画面的按键（和 Ctrl+F1 一样），并打开本手册（和 Ctrl+Shift+F1 一样）。游戏启动时，模组会在“模拟人生无障碍模组已加载”之后说出这两个按键。

## 了解更多：查看缓冲区

不是所有内容都能放进一句话里。模组保留两个可以逐行阅读的缓冲区：

- **详情**：刚才所说内容的全部信息。商品的评分、适用房间和描述；地块物品的动作、房间、距离和售价；需求或技能的说明；控件的提示文字和它在组中的位置（“第3项，共12项，控制按钮”）。
- **事件**：发生过的事，最新的在前：购买、出售、速度变化、对话框文字、排队的动作，以及旁白说过的一切（保留最近 200 条）。

| 按键 | 作用 |
|---|---|
| Ctrl+上方向键 | 下一行，往缓冲区深处读。 |
| Ctrl+下方向键 | 往回读，朝顶部移动。 |
| Ctrl+左方向键, Ctrl+右方向键 | 在缓冲区之间切换。 |

## 街区

街区画面的主要组是**房屋**：每栋房屋会说出地址和住在那里的人。在房屋上按回车会像点击一样激活它，接着出现游戏自己的卡片或问题。在房屋上按 Ctrl+上方向键可以读它的详情：也就是建筑模式的房屋概况会说的内容，依据房屋最后一次存档（房间、缺少什么、没有入口的房间）。Ctrl+Shift+L 一次全部说出。

其他组包含游戏的按钮：创建家庭、家庭收纳箱、街区编号、选项、退出。

没有家庭的房屋只能以建筑模式打开，资金无限；模组会说“没有家庭，资金无限”，而不是一个金额。

## 创建家庭和模拟市民

这些画面上的一切都是组或文本框：

- 在各自的文本框中输入家庭姓氏和模拟市民的名字。
- **性格**：左右方向键给每项特质加一点或减一点（“4，最大10，还剩6点”）。星座由点数决定。
- **外貌**：年龄、性别和肤色，以及头部和躯体的箭头。每个头部和躯体都有描述（“头部，第3个，共137个：金发，波波头”）。
- 个人简介也是一个文本框。
- 之后在地块上，按 Ctrl+Shift 加数字（1 到 9）可以打开模拟市民的卡片，在那里可以编辑个人简介。

## 地块：生活模式

在地块上，HUD 和任何画面一样是一圈组。Tab 按以下顺序浏览：

1. **状态栏**：时间、资金、游戏速度、朋友。
2. 所选模拟市民的**需求**，每项以百分比表示；回车说出该需求的含义。
3. **家庭**：家中的模拟市民；回车选择其中一位。
4. **动作队列**：所选模拟市民接下来要做的事；回车取消一个动作。
5. **按类型的物品**和**按房间的物品**：地块上的物品（见下文）。
6. **控制按钮**、**模拟市民面板**（状态、人际、工作和技能、性格、兴趣、房屋），以及你打开的任何面板。
7. **模组帮助**。

在生活面板的项目上（需求、技能、工作、房屋评分），回车朗读游戏为它显示的弹出说明。

工作项会说出工作时间和班车到达的时间。每项技能会说出它的等级，如果升职还需要更高，也会说出需要多少：“烹饪，2，满分10，下次升职需要4”。游戏菜单里没有辞职的选项：一直缺勤的模拟市民会被解雇，报纸和电脑可以找其他工作。

### 选择模拟市民和镜头

| 按键 | 作用 |
|---|---|
| 空格键 | 游戏的“下一个模拟市民”：选中家庭的下一位成员并朗读（“Isabel，已选中，吃”）。 |
| Ctrl+1到Ctrl+9 | 选择家庭中的第一到第九位模拟市民。 |
| Ctrl+Shift+1到Ctrl+Shift+9 | 打开该模拟市民的卡片（个人简介）。 |
| Ctrl+Shift+F | 镜头跟随所选模拟市民，或保持自由。 |
| Ctrl+E | 用一句话说出所选模拟市民：房间、正在做什么、紧急需求、心情。 |
| Ctrl+Shift+E | 模拟市民的外貌：头部和身体（“头部：黑发，短发；身体：西装，黑色”）。说的是地块物品中获得焦点的模拟市民，否则是所选的模拟市民。模拟市民的详情（在其上按Ctrl+上方向键）也会说出。 |
| Ctrl+T | 说出时钟的每个新整点（“现在是14:00”），或停止。在最快速度下很有用。 |
| P | 暂停（游戏的按键）；模组说出时间和资金。1、2、3 设置速度。 |

镜头会跟随所选的模拟市民，因为游戏的声音来自画面上的内容。浏览地块物品时，镜头会移到每个物品，之后再回到模拟市民身上。镜头会缓慢滑过去，画面不会急速移动（设置 `camera_glide`）。

缩放和镜头朝向改变时会读出（加号和减号缩放，逗号和句号旋转视图），状态行里也有：“镜头：中景，朝西北”。朝向是屏幕上方所指的方向。模组的北方不随镜头旋转。

### 地块上的物品

地块上的一切都在两个组里：**按类型的物品**（先是模拟市民，然后是购买模式的分类：坐椅、表面、家用电器……，最后是其他物品）和**按房间的物品**（先是所选模拟市民所在的房间，然后是其他房间，每个都附带楼层和大小）。在类型或房间上按回车会列出其中的物品，由近到远，以所选模拟市民为基准，例如“冰箱，厨房，东北方6格”。退格键返回类型或房间列表。房间名称是模组根据里面的东西猜出来的。

你不必用 Tab 移到那里：在地块上的任何地方，无论生活、购买还是建筑模式，Page 键都能浏览物品。

| 按键 | 作用 |
|---|---|
| Page Down, Page Up | 上次所选类型或房间中的下一个或上一个物品。 |
| Shift+Page Down, Shift+Page Up | 下一个或上一个物品类型。 |
| Ctrl+Page Down, Ctrl+Page Up | 下一个或上一个房间（第一次按：所选模拟市民所在的房间）。 |
| 回车 | 物品的互动（在购买模式中：拿起它来移动）。在相同物品的条目上（“折叠椅，4个相同”）：逐个列出它们，由近到远；退格键返回。 |
| Ctrl+回车 | 让所选模拟市民走到该物品那里。 |
| Ctrl+F | 查找东西：输入名称的一部分（不区分重音）。上下方向键浏览结果，回车操作，Ctrl+回车让模拟市民走过去，Delete移除门或窗，Esc回到原来的位置。 |
| Delete | 在门或窗上（购买或建筑模式）：移除并退款。 |

仍显示着对话泡泡的模拟市民或物品也会说出泡泡内容（“Bella，吃，在想：饥饿”）。没有模拟市民能从地块入口到达的东西会说“没有模拟市民能到达”。

模拟市民之后是**问题**：需要注意的东西，如损坏的物品、需要清洁的东西、水洼、垃圾、灰烬、火和有苍蝇的东西。空的宠物食盆也在这里；在任何列表里，食盆都会说出里面有没有食物。最后是**门、窗和楼梯**。

### 互动菜单

在物品（或模拟市民）上按回车，打开游戏的互动菜单。上下方向键选择，回车执行，Esc 返回上一层或关闭。以“...”结尾的条目会打开更多选项。选中的动作会被说成排队中（“交谈，排队中”）。菜单为空时，模组会说明原因（“没有互动。仅限儿童：游戏”）。

### 房间和房屋

| 按键 | 作用 |
|---|---|
| Ctrl+L | 房间的布局：大小、每面墙上的门窗以及它们通向哪里；沿每面墙摆放的东西在详情缓冲区里。 还会说出房间的光照，光照计入房间评分。 |
| Ctrl+Shift+L | 房屋概况：楼层、房间、评分、缺少什么（马桶、淋浴、床、冰箱、炉灶、电话、烟雾报警器）、没有入口的房间、谁都到不了的物品、昏暗或不受喜欢的房间。 |

### 房屋地图

**Ctrl+M** 打开地图：一个从所选模拟市民开始、逐格走遍房屋的光标。每走一步，都会为地板以及周围的每面墙、篱笆、门或窗播放声音。

| 按键 | 作用 |
|---|---|
| 方向键 | 移动一格；按住 Shift 移动五格。说出那里有什么、朝向哪里，房间和楼层改变时也会说出，以及各个方向的墙、篱笆、栏杆、门和窗。墙、篱笆和窗户会挡住光标；门可以通过。 随房间一起说出其光照（“光照64%”：窗户和灯；室外为日光），光照计入房间评分。 |
| Alt+方向键 | 同上，但穿过墙。 |
| 逗号, 句号 | 每一步说什么：全部、仅物品、仅地板（按名称，“浅色花岗岩地砖”）、仅墙、仅房间。 |
| Home | 回到所选模拟市民身边。 |
| Ctrl+Shift+Page Up, Page Down | 上一层或下一层。 |
| 回车 | 那里的东西的互动菜单（桌子或书桌上的东西优先于桌子：说的是电脑，而不是它的书桌）。 |
| Ctrl+回车 | 让所选模拟市民走到那里。 |
| Page Down, Page Up（以及 Shift、Ctrl） | 和平时一样浏览地块物品；地图会移到每个物品。 |
| R | 这一格的全部信息。Ctrl+L 说出房间布局。 |
| Esc 或 Ctrl+M | 离开地图。 |

### 旁白

游戏中很多事只以图像表现。模组会在它们发生时说出来，并保存在事件缓冲区里：

- 模拟市民和物品上方的**对话泡泡**：“Bella在想：饥饿”、“Mortimer在喊：小便”、“Bella在说：外星人”、对方不喜欢的话题（“...，不感兴趣”）、“关系变差”，以及“垃圾罐：苍蝇”。
- **被挡住的路线**：“Bella过不去：椅子挡住了路”。
- **访客**的到来和离开、鬼魂、窃贼、死神、比萨外卖，以及接送的车和校车（哪辆车在按喇叭）。
- 被收债员或窃贼**拿走的东西**，连同其价值；**账单**的到来。
- **家庭动态**：所选模拟市民开始做什么，是你下的命令还是自己决定的（“Cris，自己决定：就坐”）、何时做完或被打断（“Cris停下了就坐，改为惊慌；原来的动作仍在队列中等待”）、换房间、需求降低、心情变红、当天的关系变化（“Marisa与Cris：+8，现在28”；游戏的关系面板也会显示这些数字），以及在购买模式之外支付或收到的钱。
- **旅行**：你到达了哪里，以及“回到家了”。

**Ctrl+N** 改变旁白说话的多少：全部、仅警告或关闭。没有说出的内容仍会记入事件缓冲区。

**Ctrl+Shift+N** 选择朗读谁的对话（模拟市民说的话、他们的社交互动以及由此带来的关系变化）：任何与你的家庭交谈的人（初始设置）、地块上的所有人、只有你的家庭，或没有人。

听得到的声音（电话、门铃、警报）不会被朗读。

与其他模拟市民的行动会说出对方的名字，不管是谁开始的：“霍默：打招呼，对象：埃尔维拉”。

### 帮助提示和教程

当游戏的帮助系统有提示在等待时，模组会说“有一条帮助系统提示：按Ctrl+H朗读”。**Ctrl+H** 打开它：朗读提示内容，或者说出游戏的红色箭头指向什么。

第一个街区的 7 号房屋运行游戏的教程。每一步都会以游戏文字的键盘版本朗读（“按放大镜头按钮：Tab移到控制按钮，方向键移到放大镜头，按回车”），然后说出箭头指向什么。每一步都能用键盘完成。教程进行中第一次按 Esc 会提醒你；四秒内再按一次 Esc 就会离开教程。

### 比萨和其他服务

用电话的互动呼叫服务。比萨外卖员必须有人问候：他到达时，移到按类型的物品，选择模拟市民，用下方向键移到他，按回车，选择“问候”。如果没人问候他，他会带着比萨离开，钱也会退回。

## 购买模式

F2 打开购买模式。目录的分类是选项卡，商品是按钮：每个商品会说出名称、价格、主要评分和描述，详情缓冲区里有它的全部评分和适用的房间。越过一页的最后一个商品会自动翻页。 每件商品还会说出以格计的大小，长边在前（“2×1格”）。金钱以游戏货币模拟币说出。

| 按键 | 作用 |
|---|---|
| Ctrl+R | 让目录只显示适合某一种房间的商品（厨房、浴室、卧室、起居室、餐厅、书房、户外），或显示全部。 |
| 退格键 | 目录的“后退”。 |
| 左方向键、右方向键 | 目录的上一页或下一页；上下键逐个浏览商品。 |
| 在商品上按回车 | 开始摆放它。 |

### 摆放物品

当你拿着一个物品时，模组已经找出了它放得下**并且能使用**的位置（依据游戏的摆放检查、房间的墙和门，以及模拟市民使用它所需的空间）。每个位置会说出它所在的房间、旁边有什么以及朝向哪里。

| 按键 | 作用 |
|---|---|
| Page Down, Page Up（或 Tab） | 各个位置，最好的在前。 |
| Ctrl+Page Down, Ctrl+Page Up | 有位置的房间。 |
| Shift+Page Down, Shift+Page Up（或逗号、句号） | 同一位置上的其他朝向。 |
| Ctrl+Shift+Page Down, Page Up | 地块上物品的旁边，由近到远。 |
| 方向键 | 改为一格一格地移动（Shift：五格），并说出是否放得下以及碰到了什么。墙、篱笆和窗户会挡住它；门可以通过。 |
| Alt+方向键 | 同上，但穿过墙。 |
| 回车 | 在那里购买（移动时则是放下）。 |
| Esc | 取消（被移动的物品回到原处）。 |
| Delete | 出售手中的物品；会说出退款金额。 |
| R | 再说一遍该位置。 |

当物品放不下方向键移到的位置时，该行最后会说出可行的办法：在同一格上能放下的朝向（“转向后可放置，
朝南”），否则是最近的能放下的格子（“最近的可放置位置：西方1格，朝北”）。对于占多格的物品，第一次
按方向键和每次转向时会说出光标在物品的哪个部分，以及其余部分延伸到哪里（“光标在其北边，延伸：南方
1格”）；位置详情中也有相同内容。

详情缓冲区里有该位置的格子坐标，以及游戏拒绝的位置和原因。

如果有需要坐着使用、却还没有座位的东西，座椅的位置会把那里排在前面：“朝南，坐着使用电脑”。物品放好后，模组会说出它将如何被使用：“坐着使用电脑”、“从办公椅上使用”、“模拟市民可以到达”或“没有模拟市民能到达”。

### 移动和出售

在购买模式中，用 Page Down 移到地块上的一个物品并按回车：它会被拿起，并出现同样的位置列表，从它原来所在的房间开始。第一次按方向键会把光标放在它原来的位置。相同的物品会逐个列出，最后买的那个会说“刚买的”。

## 建筑模式

F3 打开建筑模式。它的工具是选项卡，工具的样式是商品。进入建筑模式时会朗读房屋概况（Ctrl+Shift+L 再说一遍）。

按下工具会转到它的款式，款式在以工具命名的单独分组里；Tab回到工具。在款式上按回车之前，手里没有任何东西。

### 建造光标

在墙壁或篱笆样式上按回车，会在所选模拟市民的位置启动建造光标。它在格子之间的角点上移动。

| 按键 | 作用 |
|---|---|
| 方向键 | 移动一个角点；按住 Shift 移动五个。说出所在位置、在那里相交的墙以及那里有什么。 |
| 空格键 | 标记起点。之后光标会说出与起点的距离，以及回车会建造什么、花多少钱。 |
| 回车 | 从起点到光标建一面墙。 |
| Shift+回车 | 在起点和光标之间建造房间的四面墙。 |
| Ctrl+回车或 Delete | 拆除墙壁。 |
| 逗号、句号 | 选择现成房间的大小。 |
| Insert | 以光标处为西北角建造现成的房间。 |
| Tab, Shift+Tab（或 Ctrl+Page Down, Page Up） | 跳到下一个或上一个房间。 |
| Page Up, Page Down | 上一层或下一层。 |
| Home | 回到所选模拟市民身边。 |
| R | 全部信息：各个方向的空地、所在房间。 |
| Esc | 离开光标。 |

建造之前，模组会检查新墙。如果新墙会把模拟市民关在里面、让物品无法到达、堵住门或把地块的一部分隔开，模组会说出来，再按一次回车就照样建造。

### 地板、壁纸、泳池和地形

这些工具都有同样的格子光标（方向键、Shift 移动五格、Home、R、Esc；详细按键见 Ctrl+F1）：

- **地板**：回车给这一格铺地板，或者从用空格键标记的起点铺一个矩形；Shift+回车铺满整个房间；Ctrl+回车拆除。
- **壁纸**：回车给光标所在房间的每面墙贴壁纸；Ctrl+回车撕掉。
- **泳池**：空格键标记一个角，回车开挖；如果水会隔断什么，模组会先警告。Ctrl+回车把格子填回去。模拟市民需要泳池梯（在该工具的列表里）。
- **地形**：从标记的格子到光标整平，或者升高、降低地面。

**草地**使用同样的光标：回车涂抹光标下的格子。

### 门、窗和楼梯

门和窗像家具一样，从位置列表中摆放：“在厨房的西墙上，通向户外，这个房间的第一扇门”。

用方向键移动时，门或窗会说出将装在哪面墙上；旋转可以选择墙。放好门后，模组会说模拟市民能否通过，或者被什么挡住。以后要修改，请在**门、窗和楼梯**中或用Ctrl+F找到它：回车拿起移动，Delete移除（游戏的Ctrl+单击）。

### 屋顶

游戏会自动在墙上盖屋顶，所以没有光标，也没有东西要摆放。屋顶用具只选择整栋房子的坡度和款式。款式在游戏里没有名称：模组会说出颜色。

## 提示音

建造光标、摆放物品和房屋地图每走一步都会播放一个短促的声音：地板、各个方向的墙、篱笆、门或窗（每个方向听起来都不同）、物品、换房间、地块边缘、斜坡，以及物品是否放得下。**Ctrl+Shift+S** 关闭或打开这些声音。

## 其他按键

| 按键 | 作用 |
|---|---|
| Ctrl+Shift+C | 游戏的作弊控制台。上下方向键选择作弊码，输入的文字会加在后面，回车执行（再按一次：重复），Esc 关闭。 |
| Ctrl+Shift+V | 在屏幕上突出显示当前控件，方便明眼人帮忙。在地块上，鼠标指针也会移到获得焦点的东西。 |

| 按键 | 作用 |

| P | 暂停。 |
| 1、2、3 | 正常、快速、最快速度。 |
| 逗号、句号 | 旋转视角。 |
| 加号、减号 | 放大和缩小。 |

## 设置

模组的设置在游戏文件夹的 `SimsAccess\SimsAccess.ini` 中，位于 `[mod]` 部分。用按键更改设置时会立即保存。

| 设置 | 取值 |
|---|---|
| `narrator` | 2 全部，1 仅警告，0 关闭（Ctrl+N）。 |
| `cues` | 1 打开提示音，0 关闭（Ctrl+Shift+S）。 |
| `cue_volume` | 提示音的音量，0 到 100（默认 80）。 |
| `show_focus` | 1 在屏幕上突出显示当前控件（Ctrl+Shift+V）。 |
| `social` | 朗读谁的对话：3 所有人，2 任何与你的家庭交谈的人，1 你的家庭，0 没有人（Ctrl+Shift+N）。 |
| `hours` | 1 说出每个新整点（Ctrl+T）。 |
| `camera_glide` | 镜头滑到所浏览物品所用的时间，单位毫秒（默认 800；0 为游戏自身较快的 250）。 |

## 出现问题时

- **完全没有语音**：先启动屏幕阅读器，再启动游戏。模组的日志是 `SimsAccess\SimsAccess.log`；报告问题时请附上它。
- **“不支持的游戏版本”**：游戏已经更新；请安装模组的下一个版本。
- **某个按键没有反应**：Ctrl+F1 会说出当前位置可用的按键。

## 尚未完成

《度假》、《超级巨星》和《魔法世界》各自的旅行和画面还没有完全支持。照相模式、镜头模式和家庭相册纯属视觉功能，不在本模组范围内。
