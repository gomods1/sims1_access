シムピープル アクセシビリティは、The Sims Legacy Collection をスクリーンリーダーとキーボードだけで遊べるようにするモッドです。すべての画面、ダイアログ、パネルをスクリーンリーダー（NVDA、JAWS、ナレーターなど）で読み上げ、どこでも同じキーで移動できるようにし、目の見えないプレイヤーに必要な道具を加えます。区画のオブジェクトの一覧、家のマップ、ゲームが画面に表示するだけのことを伝えるナレーター、家具を置ける場所、壁や部屋を建てるためのカーソルです。

このマニュアルは、ゲーム中に **Ctrl+Shift+F1** で、ゲームの言語で開きます。**Ctrl+F1** で、今いる画面のキーを読み上げます。

## はじめに

1. インストーラーを実行するか、`version.dll` と `SimsAccess` フォルダーをゲームのフォルダー（`Sims.exe` があるフォルダー）にコピーします。
2. スクリーンリーダーを起動してから、Steam で The Sims Legacy Collection を起動します。
3. ゲームのウィンドウが開くと「シムピープル アクセシビリティを読み込みました」と聞こえます。ゲームは近所の画面から始まります。

モッドはゲームの言語で話します。言語を変えるには、Steam でゲームのプロパティを開き、一般、言語を選びます。モッドが話せる言語は、英語、フランス語、ドイツ語、イタリア語、スペイン語、オランダ語、デンマーク語、スウェーデン語、ノルウェー語、フィンランド語、ブラジルポルトガル語、日本語、ポーランド語、簡体字中国語、繁体字中国語、タイ語、韓国語です。

モッドは Steam の最新版のゲームで動きます。ゲームが更新されて、モッドが「対応していないゲームのバージョンです」と言ったら、モッドの次のバージョンを入れてください。

## 移動のしかた：どこでも同じキー

すべての画面、ダイアログ、パネル、モードは同じように動きます。移動するのは **グループ** の輪です（ダイアログのボタン、気分、家族、カタログなど）。グループには **項目** があり、項目の中には、さらに深い **階層** を開くものがあります。

| キー | 働き |
|---|---|
| Tab、Shift+Tab | 次または前のグループ。最初にグループの名前と項目の数を読みます。 |
| 上矢印、下矢印（または左矢印、右矢印） | グループ内の前または次の項目。 |
| Home、End | グループの最初または最後の項目。 |
| Enter | 項目を押します。階層（区画のオブジェクトの種類や部屋）では、それを開きます。 |
| スペース | 押します。ただし区画の画面では、スペースはゲームの「次のシム」キーです。 |
| Backspace | 1つ上の階層に戻ります。 |
| R | 項目をグループと一緒にもう一度読みます。 |
| Escape | アクションメニューを閉じます。それ以外ではゲーム本来の Escape です。 |
| Alt+文字キー | 名前がその文字で始まる次のグループ。 |
| Ctrl+F1 | 今いる画面のキー。 |
| Ctrl+Shift+F1 | このマニュアル。 |

コントロールは、スクリーンリーダーと同じように、名前のあとに種類を言います。「保存、ボタン」「サウンドオプション、タブ、選択中」「オートセンタリング、チェックボックス、チェック」「ＳＥ、スライダー、10段階中8」「地形ディテール、セレクター、高」。

- **スライダー、セレクター、性格のバー**：左矢印と右矢印（または Page Up と Page Down）で値を変えます。Enter は値をもう一度読むだけです。
- **チェックボックス**：Enter でチェックを付けたり外したりします。
- **テキスト欄**（家族やシムの名前、バイオグラフィー）：矢印キーで欄まで移動して入力します。入力した文字は1文字ずつ読み上げられ、Backspace は消した文字を読みます。左矢印、右矢印、Home、End、Delete で欄の中を移動します。テキスト欄が画面にある間は、文字キー、スペース、R は入力になります。
- **使えないコントロール** は「利用不可」と言い、押されません。

どの画面でも最後のグループは **モッドのヘルプ** です。そのボタンで、その画面のキーを読み上げ（Ctrl+F1 と同じ）、このマニュアルを開きます（Ctrl+Shift+F1 と同じ）。ゲームが始まると、モッドは「シムピープル アクセシビリティを読み込みました」のあとに、この2つのキーを伝えます。

## もっと読む：レビューバッファー

すべてが1行の読み上げに収まるわけではありません。モッドには、1行ずつ読める2つのバッファーがあります。

- **詳細**：今読み上げたものについてのすべて。商品の評価、向いている部屋、説明。区画のオブジェクトのアクション、部屋、距離、売値。気分やスキルの説明。コントロールのツールチップと、グループの中での位置（「12件中3件目、コントロールパネル」）。
- **イベント**：起きたこと、新しい順。購入、売却、速度の変更、ダイアログの文章、待ち行列に入れたアクション、ナレーターが言ったことすべて（最新の200件）。

| キー | 働き |
|---|---|
| Ctrl+上矢印 | 次の行。バッファーの奥へ進みます。 |
| Ctrl+下矢印 | 先頭のほうへ戻ります。 |
| Ctrl+左矢印、Ctrl+右矢印 | バッファーを切り替えます。 |

## 近所

近所の画面のメイングループは **家の一覧** です。それぞれの家が住所と住んでいる人を言います。家で Enter を押すと、クリックと同じように家を押し、そのあとゲーム本来のカードや質問が出ます。家の上で Ctrl+上矢印を押すと、その家の詳細を読みます。建築モードの家の概要と同じ内容を、家の最後の保存から読みます（部屋、足りないもの、入り口のない部屋）。Ctrl+Shift+L で、すべてを一度に読みます。

ほかのグループにはゲームのボタンがあります。家族の作成、家族の保管庫、近所の番号、オプション、終了です。

家族のいない家は建築モードだけで開き、資金は無制限です。モッドは金額のかわりに「家族なし、資金無制限」と言います。

## 家族とシムを作る

この画面では、すべてがグループか入力欄です。

- 家族の名前とシムの名前を、それぞれのテキスト欄に入力します。
- **性格**：左矢印と右矢印で、それぞれの特性にポイントを足したり引いたりします（「10段階中4、残り6ポイント」）。星座はポイントで決まります。
- **外見**：年齢、性別、肌の色、頭と体の矢印。頭と体はそれぞれ説明されます（「頭 137個中3番目: 金髪、ボブ」）。
- バイオグラフィーもテキスト欄です。
- 区画で Ctrl+Shift と数字（1～9）を押すと、あとでシムのカードを開き、バイオグラフィーを編集できます。

## 区画：生活モード

区画では、HUD もほかの画面と同じグループの輪です。Tab で次の順に移動します。

1. **ステータス**：時刻、資金、ゲームの速度、友だち。
2. 選択中のシムの **気分**（欲求）。それぞれをパーセントで読みます。Enter でその欲求の意味を読みます。
3. **家族**：家族のシム。Enter で1人を選択します。
4. **アクションキュー**：選択中のシムがこれからすること。Enter でアクションを取り消します。
5. **種類別のオブジェクト** と **部屋別のオブジェクト**：区画のオブジェクト（下を参照）。
6. **コントロールパネル**、**シムパネル**（気分、人間関係、仕事とスキル、性格、興味、家）、そして開いたパネル。
7. **モッドのヘルプ**。

パネルの項目（欲求、スキル、仕事、家の評価）で Enter を押すと、ゲームのポップアップを読みます。

### シムの選択とカメラ

| キー | 働き |
|---|---|
| スペース | ゲームの「次のシム」。家族の次のメンバーを選択して伝えます（「イザベル、選択中、食べる」）。 |
| Ctrl+1～Ctrl+9 | 家族の1番目から9番目のシムを選択します。 |
| Ctrl+Shift+1～Ctrl+Shift+9 | そのシムのカード（バイオグラフィー）を開きます。 |
| Ctrl+F | カメラが選択中のシムを追うか、自由に動くかを切り替えます。 |
| Ctrl+E | 選択中のシムを1行で：部屋、していること、急ぎの欲求、気分。 |
| P | ポーズ（ゲームのキー）。モッドが時刻と資金を言います。1、2、3 で速度を変えます。 |

ゲームの音は画面に映っているものから聞こえるので、カメラは選択中のシムを追います。区画のオブジェクトを見ていく間は、カメラがそれぞれのオブジェクトへ移り、終わるとシムに戻ります。

### 区画のオブジェクト

区画にあるものはすべて2つのグループにあります。**種類別のオブジェクト**（シム、次に購入モードのカテゴリー：椅子、机、電家製品など、最後にほかのオブジェクト）と、**部屋別のオブジェクト**（最初に選択中のシムがいる部屋、次にほかの部屋。それぞれ階と広さ付き）です。種類や部屋で Enter を押すと、そのオブジェクトを近い順に、選択中のシムからの位置で「冷蔵庫、台所、北東に6マス」のように並べます。Backspace で種類や部屋に戻ります。部屋の名前は、中にあるものからモッドが推測したものです。

Tab でそこまで行く必要はありません。Page キーで、区画のどこからでも、生活モード、購入モード、建築モードでオブジェクトを見ていけます。

| キー | 働き |
|---|---|
| Page Down、Page Up | 最後に選んだ種類または部屋の、次または前のオブジェクト。 |
| Shift+Page Down、Shift+Page Up | 次または前のオブジェクトの種類。 |
| Ctrl+Page Down、Ctrl+Page Up | 次または前の部屋（最初に押したとき：選択中のシムの部屋）。 |
| Enter | オブジェクトのアクション（購入モードでは、持ち上げて移動します）。 |
| Ctrl+Enter | 選択中のシムをオブジェクトまで歩かせます。 |

まだ吹き出しが出ているシムやオブジェクトは、それも言います（「ベラ、食べる、考えている: 空腹」）。

### アクションメニュー

オブジェクト（またはシム）で Enter を押すと、ゲームのアクションメニューが開きます。上矢印と下矢印で選び、Enter で実行し、Escape で1つ前の階層に戻るか閉じます。「...」で終わる項目は、さらに選択肢を開きます。選んだアクションは待ち行列に入ったことを伝えます（「話す、待機中」）。メニューが空のときは、モッドが理由を言います（「アクションなし。子供専用：遊ぶ」）。

### 部屋と家

| キー | 働き |
|---|---|
| Ctrl+L | 部屋の配置：広さ、壁ごとのドアと窓とその行き先。それぞれの壁ぎわにあるものは詳細バッファーにあります。 |
| Ctrl+Shift+L | 家の概要：階、部屋、評価、足りないもの（トイレ、シャワー、ベッド、冷蔵庫、コンロ、電話、煙探知機）、入り口のない部屋、誰も行けないオブジェクト、暗い部屋や好まれない部屋。 |

### 家のマップ

**Ctrl+M** でマップを使います。選択中のシムから始まり、家の中を1マスずつ進むカーソルです。1歩ごとに、床の音と、周りの壁、フェンス、ドア、窓それぞれの音が鳴ります。

| キー | 働き |
|---|---|
| 矢印キー | 1マス。Shift と一緒なら5マス。そこにあるものとその向き、部屋と階が変わったときはそれも、四方の壁、フェンス、手すり、ドア、窓を読みます。 |
| Home | 選択中のシムに戻ります。 |
| Ctrl+Shift+Page Up、Page Down | 上または下の階。 |
| Enter | そこにあるもののアクションメニュー。 |
| Ctrl+Enter | 選択中のシムをそこへ歩かせます。 |
| Page Down、Page Up（と Shift、Ctrl） | いつもどおり区画のオブジェクト。マップもそれぞれへ移ります。 |
| R | そのマスのすべて。Ctrl+L で部屋の配置。 |
| Escape または Ctrl+M | マップを終わります。 |

### ナレーター

ゲームは多くのことを絵でしか見せません。モッドはそれを起きたときに伝え、イベントバッファーに残します。

- シムやオブジェクトの上の **吹き出し**：「ベラが考えている: 空腹」「モーティマーが叫んでいる: 便意」「ベラが話している: エイリアン」、相手のシムが嫌いな話題（「…、興味なし」）、「関係が悪くなった」、「ごみ箱: ハエ」。
- **ふさがれた道**：「ベラは通れません: 椅子がじゃまです」。
- 来ては帰っていく **訪問者**、幽霊、泥棒、死神、ピザの配達、相乗りの車とスクールバス（どの車がクラクションを鳴らしたか）。
- 差し押さえ屋や泥棒に **持ち去られた物** とその値段。届いた **請求書**。
- **家族の見守り**：選択中のシムが、あなたの指示で、または自分から始めたこと（「クリス、自分から：座る」）、終わったとき、部屋の移動、下がってきた欲求、赤くなった気分、その日の人間関係の変化（「マリサとクリス：+8、現在28」）、購入モード以外で払ったお金や受け取ったお金。
- **旅行**：着いた場所と「帰宅しました」。

**Ctrl+N** で読み上げる量を変えます。すべて、警告のみ、オフ。読み上げなかった行もイベントバッファーには入ります。

聞けば分かる音（電話、玄関のチャイム、警報）は伝えません。

### ヘルプのヒントとチュートリアル

ゲームのヘルプシステムにヒントが待っているとき、モッドは「ヘルプシステムのヒントがあります。コントロール+Hで読みます」と言います。**Ctrl+H** で開きます。ヒントが読み上げられるか、ゲームの赤い矢印が指しているものをモッドが伝えます。

最初の近所の7番の家では、ゲームのチュートリアルが始まります。各ステップは、ゲームの文章をキーボード用に書き直したもので読み上げられ（「ズームインボタンを押してください。タブでコントロールパネルまで、矢印キーでズームインまで移動し、エンターを押します」）、そのあと矢印が指しているものを伝えます。どのステップもキーボードで進められます。チュートリアル中の最初の Escape では注意だけを伝え、4秒以内にもう一度 Escape を押すとチュートリアルを終わります。

### ピザとほかのサービス

サービスは電話のアクションで呼びます。ピザの配達人には挨拶しなければなりません。来たら、種類別のオブジェクト、シム、下矢印で配達人まで進み、Enter、挨拶する。誰も挨拶しないと、配達人はピザを持って帰り、お金は戻ります。

## 購入モード

F2 で購入モードを開きます。カタログのカテゴリーはタブ、商品はボタンです。商品はそれぞれ名前、価格、おもな評価、説明を言い、詳細バッファーにはすべての評価と、向いている部屋があります。ページの最後の商品より先へ進むと、ページがめくれます。

| キー | 働き |
|---|---|
| Ctrl+R | カタログを1種類の部屋向けの商品（キッチン、バスルーム、寝室、リビング、ダイニング、書斎、屋外）か、すべてに絞ります。 |
| Backspace | カタログの「戻る」。 |
| 商品で Enter | 商品の配置を始めます。 |

### オブジェクトを置く

オブジェクトを持っている間、モッドはそれを置けて **使える** 場所をすでに見つけています（ゲームの配置チェック、部屋の壁とドア、シムが使うのに必要な空き）。場所は、部屋、隣にあるもの、向きを言います。

| キー | 働き |
|---|---|
| Page Down、Page Up（または Tab） | 場所。良い順。 |
| Ctrl+Page Down、Ctrl+Page Up | 置ける場所がある部屋。 |
| Shift+Page Down、Shift+Page Up（またはコンマ、ピリオド） | 同じ場所でのほかの向き。 |
| Ctrl+Shift+Page Down、Page Up | 区画のオブジェクトの隣。近い順。 |
| 矢印キー | かわりに1マスずつ動かします（Shift：5マス）。置けるかどうかと、何にぶつかるかを言います。 |
| Enter | そこに購入します（移動中なら置きます）。 |
| Escape | 取り消します（移動中のオブジェクトは元に戻ります）。 |
| Delete | 持っているオブジェクトを売ります。返ってくる金額を言います。 |
| R | 場所をもう一度読みます。 |

詳細バッファーには、その場所のマスと、ゲームが断った場所とその理由があります。

### 移動と売却

購入モードで、Page Down で区画のオブジェクトまで進んで Enter を押すと、オブジェクトを持ち上げ、同じ場所の一覧が出ます。同じオブジェクトは1つずつ並び、最後に買った物は「購入したばかり」と言います。

## 建築モード

F3 で建築モードを開きます。ツールはタブ、そのスタイルは商品です。建築モードに入ると家の概要を読み上げます（Ctrl+Shift+L でもう一度読みます）。

### 建築カーソル

壁やフェンスのスタイルで Enter を押すと、選択中のシムの位置で建築カーソルが始まります。カーソルはマスとマスの間の角を移動します。

| キー | 働き |
|---|---|
| 矢印キー | 角1つ。Shift と一緒なら5つ。位置、そこで交わる壁、そこにあるものを読みます。 |
| スペース | 開始点を決めます。そのあと、カーソルは開始点からの距離と、Enter で建つものと費用を言います。 |
| Enter | 開始点からカーソルまで壁を建てます。 |
| Shift+Enter | 開始点とカーソルの間に、部屋の4つの壁を建てます。 |
| Ctrl+Enter または Delete | 壁を撤去します。 |
| コンマ、ピリオド | 既製の部屋の大きさを選びます。 |
| Insert | 北西の角をカーソルにして、既製の部屋を建てます。 |
| Tab、Shift+Tab（または Ctrl+Page Down、Page Up） | 次または前の部屋へ移ります。 |
| Page Up、Page Down | 上または下の階。 |
| Home | 選択中のシムに戻ります。 |
| R | すべて：各方向の空き、部屋。 |
| Escape | カーソルを終わります。 |

建てる前に、モッドは新しい壁を調べます。シムを閉じ込める、オブジェクトに行けなくする、ドアをふさぐ、区画の一部を切り離す場合はそれを伝え、もう一度 Enter を押すとそのまま建てます。

### 床、壁紙、プール、地形

これらのツールには、どれもマスの上を動く同じカーソルがあります（矢印キー、Shift で5マス、Home、R、Escape。詳しくは Ctrl+F1）。

- **床**：Enter でそのマス、またはスペースで決めた開始点からの長方形に床を張ります。Shift+Enter で部屋全体。Ctrl+Enter で撤去します。
- **壁紙**：Enter でカーソルの下の部屋のすべての壁に壁紙を貼ります。Ctrl+Enter ではがします。
- **プール**：スペースで角を決め、Enter で掘ります。水が何かを切り離す前に、モッドが警告します。Ctrl+Enter でマスを埋め戻します。シムにはプール用はしご（ツールの一覧にあります）が必要です。
- **地形**：決めたマスからカーソルまでを平らにするか、地面を上げ下げします。

### ドア、窓、階段

ドアと窓は家具と同じように、場所の一覧から置きます。「台所の西の壁、屋外へ通じる、その部屋の最初のドア」。

## 効果音

建築カーソル、オブジェクトの配置、家のマップは、1歩ごとに短い音を鳴らします。床、各方向の壁、フェンス、ドア、窓（方向ごとに音が違います）、オブジェクト、部屋の変わり目、区画の端、坂、オブジェクトが置けるかどうか。**Ctrl+Shift+S** で音をオフ・オンします。

## そのほかのキー

| キー | 働き |
|---|---|
| Ctrl+Shift+C | ゲームのチートコンソール。上矢印と下矢印でチートを選び、入力で書き足し、Enter で実行（もう一度押すと繰り返し）、Escape で閉じます。 |
| Ctrl+Shift+V | 目の見える手伝いの人のために、選択中のコントロールを画面で強調します。 |

## ゲーム本来のキー

次はゲームのキーで、そのまま使えます。

| キー | 働き |
|---|---|
| F1, F2, F3, F4, F5 | 生活モード、購入モード、建築モード、カメラモード、オプションモード。 |
| P | ポーズ。 |
| 1、2、3 | 普通、速い、いちばん速い速度。 |
| コンマ、ピリオド | 視点を回します。 |
| プラス、マイナス | ズームイン、ズームアウト。 |
| Y、N | ダイアログでの「はい」と「いいえ」。 |
| Ctrl+S | 保存。 |

## 設定

モッドの設定は、ゲームのフォルダーの `SimsAccess\SimsAccess.ini` の `[mod]` セクションにあります。設定を変えるキーは、すぐに保存します。

| 設定 | 値 |
|---|---|
| `narrator` | 2 すべて、1 警告のみ、0 オフ（Ctrl+N）。 |
| `cues` | 1 効果音オン、0 オフ（Ctrl+Shift+S）。 |
| `cue_volume` | 効果音の音量、0～100（初期値 80）。 |
| `show_focus` | 1 で選択中のコントロールを画面で強調します（Ctrl+Shift+V）。 |

## うまくいかないとき

- **まったく話さない**：ゲームより先にスクリーンリーダーを起動してください。モッドのログは `SimsAccess\SimsAccess.log` です。報告のときに一緒に送ってください。
- **「対応していないゲームのバージョンです」**：ゲームが更新されました。モッドの次のバージョンを入れてください。
- **キーを押しても何も起きない**：Ctrl+F1 で、今いる場所で使えるキーを読み上げます。

## まだできていないこと

Vacation、Superstar、Makin' Magic 独自の旅行と画面には、まだ完全には対応していません。写真とカメラのモード、家族のアルバムは目で見るためだけのものなので、対象外です。
