模擬市民無障礙模組讓你只用螢幕閱讀器和鍵盤就能玩 The Sims Legacy Collection。它透過你的螢幕閱讀器（NVDA、JAWS、朗讀程式等）朗讀每個畫面、對話方塊和面板，讓你在任何地方都用同樣的按鍵瀏覽，並加入盲人玩家需要的工具：地段物品清單、房屋地圖、為遊戲只用畫面表現的內容加上的旁白、能放下家具的位置，以及建造牆壁和房間用的游標。

在遊戲中按 **Ctrl+Shift+F1** 開啟本手冊，語言與遊戲相同。**Ctrl+F1** 說出目前畫面的按鍵。

## 開始使用

1. 執行安裝程式，或把 `version.dll` 和 `SimsAccess` 資料夾複製到遊戲資料夾（有 `Sims.exe` 的那個）。
2. 先啟動螢幕閱讀器，再從 Steam 啟動 The Sims Legacy Collection。
3. 遊戲視窗開啟時，你會聽到「模擬市民無障礙模組已載入」。遊戲從社區畫面開始。

模組使用遊戲的語言。要變更語言，請開啟 Steam，進入遊戲的「內容」，然後是「一般」、「語言」。模組支援英文、法文、德文、義大利文、西班牙文、荷蘭文、丹麥文、瑞典文、挪威文、芬蘭文、巴西葡萄牙文、日文、波蘭文、簡體中文、繁體中文、泰文和韓文。

模組適用於遊戲目前的 Steam 版本。如果遊戲更新後模組說「不支援的遊戲版本」，請安裝模組的下一個版本。

## 四處移動：一套按鍵通用

每個畫面、對話方塊、面板和模式的用法都一樣。你瀏覽的是一圈**群組**（對話方塊的按鈕、需求、家庭、目錄……）。每個群組包含若干**項目**，有些項目還能開啟更深一層的**層級**。

| 按鍵 | 作用 |
|---|---|
| Tab, Shift+Tab | 下一個或上一個群組。先說出群組的名稱和項目數。 |
| 上方向鍵、下方向鍵（或左方向鍵、右方向鍵） | 群組內的上一個或下一個項目。 |
| Home, End | 群組內的第一個或最後一個項目。 |
| Enter | 執行該項目。在層級上（地段物品的某個類型或房間）則開啟它。 |
| 空白鍵 | 執行，但在地段畫面中除外：那裡的空白鍵是遊戲的「下一個模擬人物」鍵。 |
| 退格鍵 | 返回上一個層級。 |
| R | 再說一次目前的項目，連同它所在的群組。 |
| Esc | 關閉互動選單；否則是遊戲自己的 Esc。 |
| Alt+字母 | 名稱以該字母開頭的下一個群組。 |
| Ctrl+F1 | 目前畫面的按鍵。 |
| Ctrl+Shift+F1 | 本手冊。 |

控制項會在名稱後說出自己的類型，就像螢幕閱讀器那樣：「儲存，按鈕」、「音效選項，頁籤，已選取」、「自動置中，核取方塊，已核取」、「F/X，滑桿，8，最大10」、「地表細膩度，選擇器，高」。

- **滑桿、選擇器和個性條**：左右方向鍵（或 Page Up 和 Page Down）調整數值。Enter 只會再說一次數值。
- **核取方塊**：Enter 核取或取消核取。
- **文字欄位**（家庭和模擬人物的名字、個人簡介）：用方向鍵移到欄位上，然後輸入。每個字都會被讀出，退格鍵會說出刪掉的內容。左右方向鍵、Home、End 和 Delete 在欄位內移動。只要畫面上有文字欄位，字母、空白鍵和 R 都用來輸入。
- **無法使用的控制項**會說「無法使用」，不會被執行。

每個畫面的最後一個群組是**模組說明**：其中的按鈕會說出該畫面的按鍵（和 Ctrl+F1 一樣），並開啟本手冊（和 Ctrl+Shift+F1 一樣）。遊戲啟動時，模組會在「模擬市民無障礙模組已載入」之後說出這兩個按鍵。

## 了解更多：檢視緩衝區

不是所有內容都能放進一句話裡。模組保留兩個可以逐行閱讀的緩衝區：

- **詳細資料**：剛才所說內容的完整資訊。商品的評分、適用房間和說明；地段物品的動作、房間、距離和售價；需求或技能的解釋；控制項的提示文字和它在群組中的位置（「第3項，共12項，控制按鈕」）。
- **事件**：發生過的事，最新的在前：購買、賣出、速度變化、對話方塊文字、排隊的動作，以及旁白說過的一切（保留最近 200 則）。

| 按鍵 | 作用 |
|---|---|
| Ctrl+上方向鍵 | 下一行，往緩衝區深處讀。 |
| Ctrl+下方向鍵 | 往回讀，朝頂端移動。 |
| Ctrl+左方向鍵, Ctrl+右方向鍵 | 在緩衝區之間切換。 |

## 社區

社區畫面的主要群組是**房屋**：每棟房屋會說出地址和住在那裡的人。在房屋上按 Enter 會像點擊一樣執行它，接著出現遊戲自己的卡片或問題。在房屋上按 Ctrl+上方向鍵可以讀它的詳細資料：也就是建造模式的房屋概況會說的內容，依據房屋最後一次存檔（房間、缺少什麼、沒有入口的房間）。Ctrl+Shift+L 一次全部說出。

其他群組包含遊戲的按鈕：建立家庭、家庭收納箱、社區編號、選項、退出。

沒有家庭的房屋只能以建造模式開啟，資金無限；模組會說「沒有家庭，資金無限」，而不是一個金額。

## 建立家庭和模擬人物

這些畫面上的一切都是群組或欄位：

- 在各自的文字欄位中輸入家庭姓氏和模擬人物的名字。
- **個性**：左右方向鍵替每項特質加一點或減一點（「4，最大10，還剩6點」）。星座由點數決定。
- **外貌**：年齡、性別和膚色，以及頭部和身體的箭頭。每個頭部和身體都有描述（「頭部，第3個，共137個：金髮，鮑伯頭」）。
- 個人簡介也是一個文字欄位。
- 之後在地段上，按 Ctrl+Shift 加數字（1 到 9）可以開啟模擬人物的卡片，在那裡可以編輯個人簡介。

## 地段：生活模式

在地段上，HUD 和任何畫面一樣是一圈群組。Tab 依以下順序瀏覽：

1. **狀態列**：時間、資金、遊戲速度、朋友。
2. 選取的模擬人物的**需求**，每項以百分比表示；Enter 說出該需求的意思。
3. **家庭**：家中的模擬人物；Enter 選取其中一位。
4. **動作佇列**：選取的模擬人物接下來要做的事；Enter 取消一個動作。
5. **依類型的物品**和**依房間的物品**：地段上的物品（見下文）。
6. **控制按鈕**、**模擬人物面板**（情緒、人際關係、工作和技能、個性、興趣、房屋），以及你開啟的任何面板。
7. **模組說明**。

在生活面板的項目上（需求、技能、工作、房屋評分），Enter 朗讀遊戲為它顯示的彈出說明。

工作項會說出工作時間和交通車到達的時間。每項技能會說出它的等級，如果升遷還需要更高，也會說出需要多少：「烹飪，2，滿分10，下次升遷需要4」。遊戲選單裡沒有辭職的選項：一直缺勤的模擬人物會被解雇，報紙和電腦可以找其他工作。

### 選取模擬人物和畫面

| 按鍵 | 作用 |
|---|---|
| 空白鍵 | 遊戲的「下一個模擬人物」：選取家庭的下一位成員並朗讀（「Isabel，已選取，吃」）。 |
| Ctrl+1到Ctrl+9 | 選取家庭中的第一到第九位模擬人物。 |
| Ctrl+Shift+1到Ctrl+Shift+9 | 開啟該模擬人物的卡片（個人簡介）。 |
| Ctrl+Shift+F | 畫面跟隨選取的模擬人物，或保持自由。 |
| Ctrl+E | 用一句話說出選取的模擬人物：房間、正在做什麼、緊急需求、情緒。 |
| Ctrl+Shift+E | 模擬人物的外貌：頭部和身體（「頭部：黑髮，短髮；身體：西裝，黑色」）。說的是地段物品中取得焦點的模擬人物，否則是選取的模擬人物。模擬人物的詳細資料（在其上按Ctrl+上方向鍵）也會說出。 |
| Ctrl+T | 說出時鐘的每個新整點（「現在是14:00」），或停止。在最快速度下很有用。 |
| P | 暫停（遊戲的按鍵）；模組說出時間和資金。1、2、3 設定速度。 |

畫面會跟隨選取的模擬人物，因為遊戲的聲音來自畫面上的內容。瀏覽地段物品時，畫面會移到每個物品，之後再回到模擬人物身上。畫面會緩慢滑過去，不會急速移動（設定 `camera_glide`）。

縮放和畫面朝向改變時會讀出（加號和減號縮放，逗號和句號旋轉視角），狀態列裡也有：「畫面：中景，朝西北」。朝向是螢幕上方所指的方向。模組的北方不隨畫面旋轉。

### 地段上的物品

地段上的一切都在兩個群組裡：**依類型的物品**（先是模擬人物，然後是採購模式的分類：座椅、外觀、用具……，最後是其他物品）和**依房間的物品**（先是選取的模擬人物所在的房間，然後是其他房間，每個都附帶樓層和大小）。在類型或房間上按 Enter 會列出其中的物品，由近到遠，以選取的模擬人物為基準，例如「冰箱，廚房，東北方6格」。退格鍵返回類型或房間清單。房間名稱是模組根據裡面的東西猜出來的。

你不必用 Tab 移到那裡：在地段上的任何地方，無論生活、採購還是建造模式，Page 鍵都能瀏覽物品。

| 按鍵 | 作用 |
|---|---|
| Page Down, Page Up | 上次所選類型或房間中的下一個或上一個物品。 |
| Shift+Page Down, Shift+Page Up | 下一個或上一個物品類型。 |
| Ctrl+Page Down, Ctrl+Page Up | 下一個或上一個房間（第一次按：選取的模擬人物所在的房間）。 |
| Enter | 物品的互動（在採購模式中：拿起它來移動）。在相同物品的項目上（「折疊椅，4個相同」）：逐一列出它們，由近到遠；退格鍵返回。 |
| Ctrl+Enter | 讓選取的模擬人物走到該物品那裡。 |
| Ctrl+F | 尋找東西：輸入名稱的一部分（不區分重音）。上下方向鍵瀏覽結果，Enter操作，Ctrl+Enter讓模擬人物走過去，Delete移除門或窗，Esc回到原來的位置。 |
| Delete | 在門或窗上（購買或建造模式）：移除並退款。 |

仍顯示著對話泡泡的模擬人物或物品也會說出泡泡內容（「Bella，吃，在想：飢餓度」）。沒有模擬人物能從地段入口到達的東西會說「沒有模擬人物能到達」。

模擬人物之後是**問題**：需要注意的東西，如損壞的物品、需要清潔的東西、水窪、垃圾、灰燼、火和有蒼蠅的東西。空的寵物食盆也在這裡；在任何列表裡，食盆都會說出裡面有沒有食物。最後是**門、窗和樓梯**。

### 互動選單

在物品（或模擬人物）上按 Enter，開啟遊戲的互動選單。上下方向鍵選擇，Enter 執行，Esc 返回上一層或關閉。以「...」結尾的項目會開啟更多選項。選擇的動作會被說成排隊中（「交談，排隊中」）。選單是空的時候，模組會說明原因（「沒有互動。僅限兒童：玩」）。

### 房間和房屋

| 按鍵 | 作用 |
|---|---|
| Ctrl+L | 房間的格局：大小、每面牆上的門窗以及它們通往哪裡；沿每面牆擺放的東西在詳細資料緩衝區裡。 |
| Ctrl+Shift+L | 房屋概況：樓層、房間、評分、缺少什麼（馬桶、淋浴、床、冰箱、爐子、電話、煙霧警報器）、沒有入口的房間、誰都到不了的物品、昏暗或不受喜愛的房間。 |

### 房屋地圖

**Ctrl+M** 開啟地圖：一個從選取的模擬人物開始、逐格走遍房屋的游標。每走一步，都會為地板以及周圍的每面牆、籬笆、門或窗播放聲音。

| 按鍵 | 作用 |
|---|---|
| 方向鍵 | 移動一格；按住 Shift 移動五格。說出那裡有什麼、朝向哪裡，房間和樓層改變時也會說出，以及各個方向的牆、籬笆、欄杆、門和窗。牆、籬笆和窗戶會擋住游標；門可以通過。 |
| Alt+方向鍵 | 同上，但穿過牆。 |
| 逗號, 句號 | 每一步說什麼：全部、僅物品、僅地板（依名稱，「淺色花崗岩地磚」）、僅牆、僅房間。 |
| Home | 回到選取的模擬人物身邊。 |
| Ctrl+Shift+Page Up, Page Down | 上一層或下一層。 |
| Enter | 那裡的東西的互動選單（桌子或書桌上的東西優先於桌子：說的是電腦，而不是它的書桌）。 |
| Ctrl+Enter | 讓選取的模擬人物走到那裡。 |
| Page Down, Page Up（以及 Shift、Ctrl） | 和平常一樣瀏覽地段物品；地圖會移到每個物品。 |
| R | 這一格的完整資訊。Ctrl+L 說出房間格局。 |
| Esc 或 Ctrl+M | 離開地圖。 |

### 旁白

遊戲中很多事只以圖像表現。模組會在它們發生時說出來，並保存在事件緩衝區裡：

- 模擬人物和物品上方的**對話泡泡**：「Bella在想：飢餓度」、「Mortimer在喊：小解」、「Bella在說：外星人」、對方不喜歡的話題（「...，不感興趣」）、「關係變差」，以及「垃圾筒：蒼蠅」。
- **被擋住的路線**：「Bella過不去：椅子擋住了路」。
- **訪客**的到來和離開、鬼魂、竊賊、死神、披薩外送，以及接送的車和校車（哪輛車在按喇叭）。
- 被討債員或竊賊**拿走的東西**，連同其價值；**帳單**的到來。
- **家庭動態**：選取的模擬人物開始做什麼，是你下的命令還是自己決定的（「Cris，自己決定：坐下」）、何時做完或被打斷（「Cris停下了坐下，改為驚慌；原來的動作仍在佇列中等待」）、換房間、需求降低、情緒變紅、當天的關係變化（「Marisa與Cris：+8，現在28」；遊戲的關係面板也會顯示這些數字），以及在採購模式之外支付或收到的錢。
- **旅行**：你到達了哪裡，以及「回到家了」。

**Ctrl+N** 改變旁白說話的多寡：全部、僅警告或關閉。沒有說出的內容仍會記入事件緩衝區。

**Ctrl+Shift+N** 選擇朗讀誰的對話（模擬人物說的話、他們的社交互動以及由此帶來的關係變化）：任何與你的家庭交談的人（初始設定）、地段上的所有人、只有你的家庭，或沒有人。

聽得到的聲音（電話、門鈴、警報）不會被朗讀。

與其他模擬人物的行動會說出對方的名字，不管是誰開始的：「霍默：打招呼，對象：艾薇拉」。

### 說明提示和教學

當遊戲的說明系統有提示在等待時，模組會說「有一則說明系統提示：按Ctrl+H朗讀」。**Ctrl+H** 開啟它：朗讀提示內容，或說出遊戲的紅色箭頭指向什麼。

第一個社區的 7 號房屋執行遊戲的教學。每一步都會以遊戲文字的鍵盤版本朗讀（「按畫面放大按鈕：Tab移到控制按鈕，方向鍵移到畫面放大，按Enter」），然後說出箭頭指向什麼。每一步都能用鍵盤完成。教學進行中第一次按 Esc 會提醒你；四秒內再按一次 Esc 就會離開教學。

### 披薩和其他服務

用電話的互動叫服務。披薩外送員必須有人問候：他到達時，移到依類型的物品，選擇模擬人物，用下方向鍵移到他，按 Enter，選擇「問候」。如果沒人問候他，他會帶著披薩離開，錢也會退回。

## 採購模式

F2 開啟採購模式。目錄的分類是頁籤，商品是按鈕：每個商品會說出名稱、價格、主要評分和說明，詳細資料緩衝區裡有它的所有評分和適用的房間。越過一頁的最後一個商品會自動翻頁。

| 按鍵 | 作用 |
|---|---|
| Ctrl+R | 讓目錄只顯示適合某一種房間的商品（廚房、浴室、臥室、客廳、餐廳、書房、屋外），或顯示全部。 |
| 退格鍵 | 目錄的「返回」。 |
| 在商品上按 Enter | 開始擺放它。 |

### 擺放物品

當你拿著一個物品時，模組已經找出它放得下**而且能使用**的位置（依據遊戲的擺放檢查、房間的牆和門，以及模擬人物使用它所需的空間）。每個位置會說出它所在的房間、旁邊有什麼以及朝向哪裡。

| 按鍵 | 作用 |
|---|---|
| Page Down, Page Up（或 Tab） | 各個位置，最好的在前。 |
| Ctrl+Page Down, Ctrl+Page Up | 有位置的房間。 |
| Shift+Page Down, Shift+Page Up（或逗號、句號） | 同一位置上的其他朝向。 |
| Ctrl+Shift+Page Down, Page Up | 地段上物品的旁邊，由近到遠。 |
| 方向鍵 | 改為一格一格地移動（Shift：五格），並說出是否放得下以及碰到了什麼。牆、籬笆和窗戶會擋住它；門可以通過。 |
| Alt+方向鍵 | 同上，但穿過牆。 |
| Enter | 在那裡購買（移動時則是放下）。 |
| Esc | 取消（被移動的物品回到原處）。 |
| Delete | 賣掉手中的物品；會說出退款金額。 |
| R | 再說一次該位置。 |

詳細資料緩衝區裡有該位置的格子座標，以及遊戲拒絕的位置和原因。

如果有需要坐著使用、卻還沒有座位的東西，座椅的位置會把那裡排在前面：「朝南，坐著使用電腦」。物品放好後，模組會說出它將如何被使用：「坐著使用電腦」、「從辦公椅上使用」、「模擬人物可以到達」或「沒有模擬人物能到達」。

### 移動和賣出

在採購模式中，用 Page Down 移到地段上的一個物品並按 Enter：它會被拿起，並出現同樣的位置清單，從它原來所在的房間開始。第一次按方向鍵會把游標放在它原來的位置。相同的物品會逐一列出，最後買的那個會說「剛買的」。

## 建造模式

F3 開啟建造模式。它的工具是頁籤，工具的樣式是商品。進入建造模式時會朗讀房屋概況（Ctrl+Shift+L 再說一次）。

按下工具會轉到它的款式，款式在以工具命名的單獨群組裡；Tab回到工具。在款式上按Enter之前，手裡沒有任何東西。

### 建造游標

在牆壁或籬笆樣式上按 Enter，會在選取的模擬人物的位置啟動建造游標。它在格子之間的角點上移動。

| 按鍵 | 作用 |
|---|---|
| 方向鍵 | 移動一個角點；按住 Shift 移動五個。說出所在位置、在那裡相交的牆以及那裡有什麼。 |
| 空白鍵 | 標記起點。之後游標會說出與起點的距離，以及 Enter 會建造什麼、花多少錢。 |
| Enter | 從起點到游標建一面牆。 |
| Shift+Enter | 在起點和游標之間建造房間的四面牆。 |
| Ctrl+Enter 或 Delete | 拆除牆壁。 |
| 逗號、句號 | 選擇現成房間的大小。 |
| Insert | 以游標處為西北角建造現成的房間。 |
| Tab, Shift+Tab（或 Ctrl+Page Down, Page Up） | 跳到下一個或上一個房間。 |
| Page Up, Page Down | 上一層或下一層。 |
| Home | 回到選取的模擬人物身邊。 |
| R | 完整資訊：各個方向的空地、所在房間。 |
| Esc | 離開游標。 |

建造之前，模組會檢查新牆。如果新牆會把模擬人物關在裡面、讓物品無法到達、堵住門或把地段的一部分隔開，模組會說出來，再按一次 Enter 就照樣建造。

### 地板、壁紙、泳池和地形

這些工具都有同樣的格子游標（方向鍵、Shift 移動五格、Home、R、Esc；詳細按鍵見 Ctrl+F1）：

- **地板**：Enter 替這一格鋪地板，或從用空白鍵標記的起點鋪一個矩形；Shift+Enter 鋪滿整個房間；Ctrl+Enter 拆除。
- **壁紙**：Enter 替游標所在房間的每面牆貼壁紙；Ctrl+Enter 撕掉。
- **泳池**：空白鍵標記一個角，Enter 開挖；如果水會隔斷什麼，模組會先警告。Ctrl+Enter 把格子填回去。模擬人物需要泳池梯（在該工具的清單裡）。
- **地形**：從標記的格子到游標整平，或者升高、降低地面。

**草地**使用同樣的游標：Enter塗抹游標下的格子。

### 門、窗和樓梯

門和窗像家具一樣，從位置清單中擺放：「在廚房的西牆上，通往屋外，這個房間的第一扇門」。

用方向鍵移動時，門或窗會說出將裝在哪面牆上；旋轉可以選擇牆。放好門後，模組會說模擬人物能否通過，或者被什麼擋住。以後要修改，請在**門、窗和樓梯**中或用Ctrl+F找到它：Enter拿起移動，Delete移除（遊戲的Ctrl+點按）。

### 屋頂

遊戲會自動在牆上蓋屋頂，所以沒有游標，也沒有東西要擺放。屋頂工具只選擇整棟房子的坡度和款式。款式在遊戲裡沒有名稱：模組會說出顏色。

## 提示音

建造游標、擺放物品和房屋地圖每走一步都會播放一個短促的聲音：地板、各個方向的牆、籬笆、門或窗（每個方向聽起來都不同）、物品、換房間、地段邊緣、斜坡，以及物品是否放得下。**Ctrl+Shift+S** 關閉或開啟這些聲音。

## 設定

模組的設定在遊戲資料夾的 `SimsAccess\SimsAccess.ini` 中，位於 `[mod]` 區段。用按鍵變更設定時會立即儲存。

| 設定 | 值 |
|---|---|
| `narrator` | 2 全部，1 僅警告，0 關閉（Ctrl+N）。 |
| `cues` | 1 開啟提示音，0 關閉（Ctrl+Shift+S）。 |
| `cue_volume` | 提示音的音量，0 到 100（預設 80）。 |
| `show_focus` | 1 在螢幕上標示目前的控制項（Ctrl+Shift+V）。 |
| `social` | 朗讀誰的對話：3 所有人，2 任何與你的家庭交談的人，1 你的家庭，0 沒有人（Ctrl+Shift+N）。 |
| `hours` | 1 說出每個新整點（Ctrl+T）。 |
| `camera_glide` | 畫面滑到所瀏覽物品所用的時間，單位毫秒（預設 800；0 為遊戲本身較快的 250）。 |

## 發生問題時

- **完全沒有語音**：先啟動螢幕閱讀器，再啟動遊戲。模組的記錄檔是 `SimsAccess\SimsAccess.log`；回報問題時請附上它。
- **「不支援的遊戲版本」**：遊戲已經更新；請安裝模組的下一個版本。
- **某個按鍵沒有反應**：Ctrl+F1 會說出目前位置可用的按鍵。
